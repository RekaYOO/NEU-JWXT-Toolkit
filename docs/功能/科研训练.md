# 科研训练

科研训练页面封装教务系统 `kyxlneu` 应用的学生课题报名能力，支持：

- 当前报名批次和资格规则；
- 课题分页与按题目、科研项目、导师搜索；
- 课题详情；
- 报名、取消报名；
- 已确认课题与科研记录次数查询。

## 官方页面“报名无响应”的原因

官方页面点击“报名”后，会先调用 `cxxsjdjzypm` 获取学生平均绩点和
专业排名，再打开报名表单。当前测试账号的该接口返回空列表，官方
脚本仍直接访问 `rows[0].PJJD/ZYPM`，因此发生 JavaScript 异常且没有
任何用户提示。

本项目不会静默失败：资格数据为空时显示明确警告并禁用报名按钮。
这不是本地程序无法提交，而是教务系统没有提供报名表单所需的只读
绩点和排名数据。资格数据正常的账号可以填写联系电话、电子邮箱和
申请理由，并在二次确认后调用官方保存接口。

## 官方接口

```text
POST /jwapp/sys/kyxlneu/modules/kyxl/cxdqxnxqpc.do
POST /jwapp/sys/kyxlneu/modules/kyxl/ktbmcxlb.do
POST /jwapp/sys/kyxlneu/modules/kyxl/cxxsjdjzypm.do
POST /jwapp/sys/kyxlneu/modules/jsktgl/ktsbglcxlb.do
POST /jwapp/sys/kyxlneu/modules/kyxl/yqrktcxlb.do
POST /jwapp/sys/kyxlneu/api/kyxl/ktbm/save.do
POST /jwapp/sys/kyxlneu/api/kyxl/ktbm/qxbm.do
```

报名表单遵循官方限制：

- 联系电话必填，最多 16 个字符；
- 电子邮箱必填，最多 20 个字符；
- 申请理由最多 300 个字符；
- 平均绩点和专业排名只从教务系统读取，用户不能自行修改。

科研周记编辑和学习总结附件上传属于确认课题后的第二阶段，首版暂不
提供写入操作，但会显示已确认课题和当前科研记录次数。
