# 科研训练

科研训练页面封装教务系统 `kyxlneu` 应用的学生课题报名能力，支持：

- 当前报名批次和资格规则；
- 课题分页与按题目、科研项目、导师搜索；
- 完整课题本地缓存与后台更新检查；
- 按批次收藏课题，并保留已过期收藏；
- 课题详情；
- 报名、取消报名；
- 已确认课题与科研记录次数查询。

## 本地优先与收藏

页面包含“课题报名 / 我收藏的课题 / 已确认课题”三个标签。首次成功加载会顺序获取
当前批次的全部课题分页，只有全部分页成功后才原子替换 `cache.db` 中当前账号的
`research-training` 资源。以后打开页面时先显示该完整快照，再按五分钟时效在后台
静默同步：

- 首次同步只建立缓存，不把全部课题提示为新增；
- 同一批次新增、修改、下架，或已确认课题发生变化时，弹窗询问是否刷新当前页面；
- 新批次单独提示，不把整批课题逐个描述为新增；
- 后台同步失败时继续显示旧快照，不清空当前列表；
- 筛选和分页在完整本地快照上进行，不会为不同搜索条件创建碎片缓存。

不同标签或组件同时打开页面时，后端 single-flight 只执行一个完整同步；所有远端请求
还会与其他教务操作共享 Session 互斥。远端分页提前结束、课题总数在分页中变化或任一
页失败时，本次同步整体放弃并保留旧缓存。

收藏使用 `(batch_id, topic_id)` 作为唯一标识并写入
`research_training_favorites.json`。当前批次中未收藏且已经下架的课题会随完整快照
替换而删除；已收藏课题会保留最小展示快照，在收藏标签中标记“已过期”并禁止详情和
报名。用户取消收藏后，对应的过期归档立即删除。不同登录学号的缓存和收藏不会混用。

课题缓存只用于快速展示，不能作为远端写操作的最终依据。在线读取缓存和修改收藏只接受
已经完成登录的内存账号，不触发远端健康检查；尚未完成的二维码/短信流程不能读取
在线缓存接口。后台同步、详情、报名和取消报名仍需要有效 NEU 会话并以教务端状态为准，
成功后立即刷新完整快照。

已有科研训练快照时，离线导航会开放该页面，并保留本地搜索、筛选、分页以及三个标签
的查看能力。离线页面不加载按需详情，并禁用刷新、收藏变更、报名和取消报名，保证不会
通过任何按钮连接教务系统。Linux 下离线 API 仍受网站访问密码保护。

## 官方页面“报名无响应”的原因

官方页面点击“报名”后，会先调用 `cxxsjdjzypm` 获取学生平均绩点和
专业排名，再打开报名表单。当前测试账号的该接口返回空列表，官方
脚本仍直接访问 `rows[0].PJJD/ZYPM`，因此发生 JavaScript 异常且没有
任何用户提示。

本项目不会静默失败：资格数据为空时显示明确警告并禁用报名按钮。
这不是本地程序无法提交，而是教务系统没有提供报名表单所需的只读
绩点和排名数据。资格数据正常的账号可以填写联系电话、电子邮箱和
申请理由，并在二次确认后调用官方保存接口。

## 官方接口

```text
POST /jwapp/sys/kyxlneu/modules/kyxl/cxdqxnxqpc.do
POST /jwapp/sys/kyxlneu/modules/kyxl/ktbmcxlb.do
POST /jwapp/sys/kyxlneu/modules/kyxl/cxxsjdjzypm.do
POST /jwapp/sys/kyxlneu/modules/jsktgl/ktsbglcxlb.do
POST /jwapp/sys/kyxlneu/modules/kyxl/yqrktcxlb.do
POST /jwapp/sys/kyxlneu/api/kyxl/ktbm/save.do
POST /jwapp/sys/kyxlneu/api/kyxl/ktbm/qxbm.do
```

工具箱本地接口：

```text
GET  /api/research-training/cache
POST /api/research-training/refresh
POST /api/research-training/favorite
GET  /api/offline/research-training
```

报名表单遵循官方限制：

- 联系电话必填，最多 16 个字符；
- 电子邮箱必填，最多 20 个字符；
- 申请理由最多 300 个字符；
- 平均绩点和专业排名只从教务系统读取，用户不能自行修改。

科研周记编辑和学习总结附件上传属于确认课题后的第二阶段，首版暂不
提供写入操作，但会显示已确认课题和当前科研记录次数。
