# 离线使用

## 目标与边界

离线模式用于教务系统暂时不可用或设备无法联网时，快速查看当前设备已经保存的可重建
缓存。它不是模拟登录，也不会尝试访问教务系统。

离线模式只开放：

- 已保存成绩；
- 已按需保存的单科分项成绩；
- 已保存培养计划；
- 已保存科研训练快照；
- 基于上述缓存的只读查看和本地 GPA 模拟。

科研训练页离线保留搜索、筛选、分页和课题列表，但刷新、按需详情、收藏变更、报名与
取消报名均禁用。评教、实验选课、成绩追踪配置、考试刷新、日志管理等没有离线缓存或
属于联网/管理性质的功能不会在离线导航中开放。

## 入口与状态

登录页先查询 `/api/offline/status`。只要任一登记为 `offline_readable` 的功能缓存存在，
就可以进入，导航只显示当前设备确实有缓存的页面。
浏览器使用会话级标记恢复离线状态；若缓存后来不存在，则清除标记并回退到正常在线
登录状态检查。

在线使用期间若教务会话失效，后端会先用本地保存的匹配账号密码静默恢复。只有恢复
失败才通知前端；此时有离线缓存则询问“进入离线模式/重新登录”，没有缓存则返回登录页。
这个过程不会执行清理数据的登出操作。

用户菜单中的“退出离线模式”只退出前端离线会话，不调用 NEU 登出，也不删除缓存。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/offline/status` | 返回可用缓存类型和只读标记 |
| GET | `/api/offline/scores` | 从共享成绩缓存读取 |
| GET | `/api/offline/scores/details` | 按课程号和学期读取已保存分项，不联网 |
| GET | `/api/offline/academic-report` | 从共享培养计划缓存读取 |
| GET | `/api/offline/research-training` | 从共享科研训练缓存读取 |

实现位于 `backend/app/routers/offline.py`。前端入口和路由约束位于
`frontend/src/App.js`、`frontend/src/pages/LoginPage.js` 和
`frontend/src/layouts/MainLayout.js`。

## 安全要求

- 离线 API 返回个人数据，不是公开接口。
- Linux server 模式下必须先通过网站访问密码；离线不能绕过访问网关。
- 路由只读本地缓存，不调用认证客户端，不刷新远端数据，不提供写接口。
- 缓存缺失返回明确的 404/空状态，不能静默切换成远端请求。
- 数据目录与文件权限遵循[数据存储](../开发/数据存储.md)。

## 修改时必须联动

- 成绩或培养计划 HTTP 模型变化时，同步修改离线返回，保持在线/离线字段兼容。
- 存储格式变化时提供旧缓存兼容或迁移，并增加离线回归测试。
- 新功能是否支持离线必须明确决策；默认不因“页面可打开”就开放。
- 离线页面的刷新、写入和远端导入操作必须禁用，并解释原因。
- server 模式新增离线路径后，增加“未验证网站密码返回 401”的测试。
