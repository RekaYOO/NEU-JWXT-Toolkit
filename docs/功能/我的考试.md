# 我的考试

查询考试安排、按状态分类展示、导出 ICS 日历文件。

## 功能概述

- **考试列表**：获取指定学期的全部考试安排
- **状态分类**：按"未开始 / 进行中 / 已结束"三色分组展示
- **详情卡片**：课程名称、考试时间、考场、座位号、教师、考试类型
- **ICS 导出**：一键导出 `.ics` 文件，支持导入 Google Calendar / Outlook / Apple Calendar
- **自动提醒**：导出的日历事件包含考前 24h 和 2h 提醒

## API 端点

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/exams/terms` | GET | 获取学期列表 |
| `/api/exams?term_code=xxx` | GET | 获取考试安排（含分类统计） |
| `/api/exams/export-ics?term_code=xxx` | GET | 导出 ICS 日历文件 |

## 数据来源

接口来源：`https://jwxt.neu.edu.cn/jwapp/sys/homeapp`

- `POST /api/home/student/exams.do` — 考试列表（需 `termCode` 参数）
- `GET /api/home/kb/xnxq.do` — 学期列表

认证方式：CAS Session Cookie（与成绩查询共享同一套认证）

## 数据模型

### ExamItem

```python
{
    "task_id": str,            # 考试任务唯一 ID
    "course_name": str,        # 课程名称
    "course_no": str,          # 课程编号
    "course_desc": str,        # 课程描述
    "exam_type": str,          # 考试类型（如"期末考试"）
    "exam_type_code": str,     # 类型代码（01=期末）
    "exam_status": int,        # 0=未开始, 1=进行中, 2=已结束
    "exam_date": str,          # 日期 yyyy-MM-dd 00:00:00
    "exam_time_description": str,  # 完整时间描述
    "week": int,               # 教学周次
    "exam_place": str,         # 考场地点
    "exam_seat_no": str,       # 座位号
    "teachers": str,           # 任课教师
}
```

### 状态枚举

| 值 | 含义 | 颜色 |
|---|---|---|
| 0 | 未开始（NOSTART） | 蓝色 |
| 1 | 进行中（PROGRESS） | 橙色 |
| 2 | 已结束（END） | 灰色 |

## ICS 导出格式

生成的 `.ics` 文件符合 RFC 5545 标准：

```
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//NEU-JWXT-Toolkit//Exam Schedule//ZH
...
BEGIN:VEVENT
UID:... 
DTSTART;TZID=Asia/Shanghai:20260508T101000
DTEND;TZID=Asia/Shanghai:20260508T121000
SUMMARY:【期末考试】技术经济学
LOCATION:1号A405
DESCRIPTION:课程: 技术经济学\n时间: ...\n座位: 8
BEGIN:VALARM
ACTION:DISPLAY
TRIGGER:-PT24H
END:VALARM
END:VEVENT
END:VCALENDAR
```

## 前端页面

### 页面结构

```
我的考试
├── 学期选择器 + 导出 ICS 按钮
├── 统计卡片行（总考试 / 待考 / 进行中 / 已结束）
└── 考试卡片列表（按状态分组）

    ├── 进行中（橙色左边框）
    └── 已结束（灰色左边框，透明度降低）
```
