# 我的考试

查询考试安排、按状态分类展示、导出 ICS 日历文件。

读取考试数据或生成日历期间退出账号，需重新登录后再查询或下载。

## Go重构分支进度

Go入口已接通学期、考试列表和ICS导出。学校失败或响应异常会返回错误，不伪装成空考试列表。
日历使用UTC时间表达同一北京时间，事件ID在重复导出时保持稳定；中文长行按UTF-8安全折行，
课程文本中的换行、逗号和分号会转义。时间尚未明确的考试不生成事件，全部无法解析时返回提示；
部分跳过数量通过`X-Skipped-Exams`响应头返回。保留考前24小时和2小时提醒。
协议测试通过。RC26 网页下载的 Go 生成样例可由 khal 0.14.1 读取，显示北京时间、中文课程和含标点的地点。通过 icalcli 的文件接口将事件保存到空日历并重新打开后，事件标识、起止时间、课程、地点和两次提醒均保留。真实学校数据及主流图形日历客户端仍待验收。

## 功能概述

切换学期时清空上一学期的考试和统计，所选学期成功返回考试后才可导出。查询失败时显示错误提示。

- **考试列表**：获取指定学期的全部考试安排
- **状态分类**：按"未开始 / 进行中 / 已结束"三色分组展示
- **详情卡片**：课程名称、考试时间、考场、座位号、教师、考试类型
- **ICS 导出**：一键导出 `.ics` 文件，支持导入 Google Calendar / Outlook / Apple Calendar
- **自动提醒**：导出的日历事件包含考前 24h 和 2h 提醒

## API 端点

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/exams/terms` | GET | 获取学期列表 |
| `/api/exams?term_code=xxx` | GET | 获取考试安排（含分类统计） |
| `/api/exams/export-ics?term_code=xxx` | GET | 导出 ICS 日历文件 |

## 数据来源

接口来源：`https://jwxt.neu.edu.cn/jwapp/sys/homeapp`

- `POST /api/home/student/exams.do` — 考试列表（需 `termCode` 参数）
- `GET /api/home/kb/xnxq.do` — 学期列表

认证方式：CAS Session Cookie（与成绩查询共享同一套认证）

## 数据模型

### ExamItem

```python
{
    "task_id": str,            # 考试任务唯一 ID
    "course_name": str,        # 课程名称
    "course_no": str,          # 课程编号
    "course_desc": str,        # 课程描述
    "exam_type": str,          # 考试类型（如"期末考试"）
    "exam_type_code": str,     # 类型代码（01=期末）
    "exam_status": int,        # 0=未开始, 1=进行中, 2=已结束
    "exam_date": str,          # 日期 yyyy-MM-dd 00:00:00
    "exam_time_description": str,  # 完整时间描述
    "week": int,               # 教学周次
    "exam_place": str,         # 考场地点
    "exam_seat_no": str,       # 座位号
    "teachers": str,           # 任课教师
}
```

### 状态枚举

| 值 | 含义 | 颜色 |
|---|---|---|
| 0 | 未开始（NOSTART） | 蓝色 |
| 1 | 进行中（PROGRESS） | 橙色 |
| 2 | 已结束（END） | 灰色 |

## ICS 导出格式

生成的 `.ics` 文件符合 RFC 5545 标准：

```
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//NEU-JWXT-Toolkit//Exam Schedule//ZH
...
BEGIN:VEVENT
UID:... 
DTSTART;TZID=Asia/Shanghai:20260508T101000
DTEND;TZID=Asia/Shanghai:20260508T121000
SUMMARY:【期末考试】技术经济学
LOCATION:1号A405
DESCRIPTION:课程: 技术经济学\n时间: ...\n座位: 8
BEGIN:VALARM
ACTION:DISPLAY
TRIGGER:-PT24H
END:VALARM
END:VEVENT
END:VCALENDAR
```

## 前端页面

- **路径**: `/exams`
- **组件**: `frontend/src/pages/ExamPage.js`
- **样式**: `frontend/src/pages/ExamPage.css`

### 页面结构

```
我的考试
├── 学期选择器 + 导出 ICS 按钮
├── 统计卡片行（总考试 / 待考 / 进行中 / 已结束）
└── 考试卡片列表（按状态分组）
    ├── 待考（蓝色左边框）
    ├── 进行中（橙色左边框）
    └── 已结束（灰色左边框，透明度降低）
```

页面同时静默读取教务系统消息缓存，只识别考务管理、考试、考场、座位、监考和考试安排相关通知。
仅弹出官方未读消息；点击“知道了”后逐条调用教务系统消息中心的官方已读接口，
并同步更新本地消息缓存，因此同一登录会话内切页或重新打开考试页不会重复弹出已确认通知。
提示复用现有更新摘要弹窗样式；
消息读取失败、缓存过期不会阻断考试数据。
