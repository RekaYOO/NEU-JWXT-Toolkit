# 系统缓存设置

Go 新版的系统设置提供当前账号的缓存策略，其他账号保持各自设置。配置保存到服务器，
重新登录或换浏览器后仍可读取。只列出实际登记的可重建资源；收藏、日程、选课方案、
课程归档、可靠提交记录和邮件队列不属于缓存策略范围。

## 开关和间隔

“新鲜度复用”启用时，检查间隔决定已有快照多久之后需要重新检查；单位为整数分钟，
范围为 1～52,560,000。主动刷新、业务操作导致的失效和 Schema 不兼容不受此间隔阻止。
关闭时，快照始终标记为待检查，在线页面仍可先显示快照并请求后台更新。
已保存数据继续支持离线查看及网络失败时回退；该开关不删除数据，也不是禁止落盘开关。
任务合并、失败退避和短时间防重复仍然生效。

这保留旧版协调器 `enabled=false` 的实际行为，并纠正旧页面“不会继续使用本地缓存”
的误导性说明。浏览器课表及头像快照由各自的清除按钮管理，不受此开关删除。
课程大纲“未找到”的负缓存仍最多复用七天，用户设置更长间隔也不会突破此上限。

保存支持部分资源更新，其他资源不变；无效资源、非整数、越界值和额外字段会整次拒绝。
保存失败时保留旧设置，不会部分生效。退出或被撤销的会话不能修改设置。
