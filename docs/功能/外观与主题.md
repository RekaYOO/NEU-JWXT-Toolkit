# 外观与主题

进入“系统设置 → 外观与主题”管理当前账号的外观。

默认的晴蓝沿用原版导航选中色、金色强调色、按钮、表格与阴影。个人预览其他模板后可选择晴蓝恢复原版配色。

成绩追踪页的标题底色、图标和设置区域随主题预览更新，晴蓝使用原版浅蓝渐变。

选课策略说明、实验课程文字与分隔线、评教面板底色使用个人主题。切回晴蓝时，这些区域采用原版配色。

个人主题下，课表卡片使用模板面板底色，课程边框保留课程色。地点、教师、叠课详情和手机摘要使用模板文字色。晴蓝沿用原版课程填充色。

## 内置模板与预览

内置樱空、晴蓝、青庭三套模板，分别使用粉、蓝、青绿主色；操作的成功、警告、错误语义保持不变。
“预览”立即显示模板但不保存，“取消预览”或离开外观页恢复已应用的外观。
切换账号后，旧账号尚未发出的保存和预览不会作用于新账号。连续导入多个文件时，以最后选择的文件为准，不会自动保存。
“应用”将选择保存到当前账号，同站点再次登录或换设备后读取服务器设置。
“恢复站点默认”清除个人选择，但保留个人模板。

## 自定义与文件

新构建的 Go 运行包在 `themes/` 提供樱空（`sakura.json`）、晴蓝（`blue.json`）和青庭（`garden.json`），与页面内置模板使用同一份数据。通过“导入主题 JSON”选择文件即可预览，保存为个人副本后生效。

可以从已有模板创建副本，修改名称、六种基础颜色、本机字体类别、圆角、轻柔阴影及动效。
保存会同时应用模板，最多保留 32 个个人模板。内置模板不会被编辑覆盖。
删除正在使用的个人模板后恢复站点默认；其他个人模板不变。

导出生成 JSON 文件。导入先校验并打开编辑器，随后可预览和保存为个人副本，
不会静默覆盖同名模板或当前设置。文件最大 16 KB，只接受版本 1 的约定字段；
不支持 CSS、脚本、远程图片或远程字体。正文、辅助文字和主色须满足至少 4.5:1 对比度。
导航选中项通常使用模板主色。如果主色在导航选中背景上的对比度低于 4.5:1，该项文字改用模板正文色，按钮主色和已保存的模板文件不变。
校验或保存失败保留原设置和正在编辑的内容。

## 账号、站点和设备

考试页的待考数量和卡片标记使用个人主题主色。学业报告的课程类别按层级使用主题主色、正文色和辅助文字色，已选课数量使用主题主色。

旧数据中无法识别的站点主题显示为晴蓝，管理员可从该页重新选择并保存。
管理员可在账号管理页选择站点默认内置模板。个人选择优先于站点默认；设备的
“减少动态效果”优先于模板动效。多设备同时编辑发生冲突时，页面提示重新读取，
不会静默覆盖另一设备已保存的修改。

换号或退出后立即清除前一账号在页面内存中的个人外观，不将模板保存到共用浏览器存储。
主题变化不重新挂载业务页面，不改变课程数据或清空业务输入。

当前已接通设置流程、应用框架和 Ant Design 组件的主题映射。历史业务页面中直接写定的
颜色与图表配色仍在逐项统一，尚未宣称全应用主题覆盖验收完成。网站访问门、学校登录、
管理员登录、远程恢复及启动加载页面使用站点默认主题；读取默认失败时回退晴蓝，
不阻塞登录操作。公共页面只读取内置模板标识，不读取任何账号的私人模板。

访问密码页的说明文字随站点主题调整。提交空表单时，密码框下方会显示“请输入访问密码”。三套内置主题的标题、说明和这条提示均已在 320 和 1440 像素宽度下检查文字对比度。
