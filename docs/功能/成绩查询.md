# 成绩明细

桌面成绩表首次使用或恢复默认列时显示“课程名称、成绩、绩点、学分、学期、课程性质、
考核方式、状态”；课程代码仍可在列设置中开启。已有用户列设置继续按本地配置恢复，新增
默认值不会擅自覆盖用户已经保存的选择。

## 统一入口

所有功能通过 `NEUAuthClient` 实例访问：

```python
from backend.core.auth import NEUAuthClient

auth = NEUAuthClient("学号", "密码")
auth.login(target="https://jwxt.neu.edu.cn")

# 成绩功能
auth.academic.get_scores()
auth.academic.get_overall_gpa()
```

## 成绩模块 (backend.core.academic)

### AcademicAPI

挂载点：`NEUAuthClient.academic`

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `get_terms` | - | List[Dict] | 获取有成绩的学期列表 |
| `get_scores` | term="" | List[CourseScore] | 获取成绩，空字符串=全部 |
| `get_overall_gpa` | - | float / None | 系统计算的总绩点 |
| `calculate_gpa` | scores | float | 使用系统绩点计算GPA |
| `get_scores_by_term` | - | List[TermScores] | 按学期分组获取成绩 |
| `get_score_detail` | detail_ref | CourseScoreDetail | 获取单科动态分项成绩 |

**常量定义：**
```python
TERMS_URL = "https://jwxt.neu.edu.cn/jwapp/sys/cjzhcxapp/modules/wdcj/cxwdcjxnxq.do"
SCORES_URL = "https://jwxt.neu.edu.cn/jwapp/sys/cjzhcxapp/modules/wdcj/cxwdcj.do"
GPA_URL = "https://jwxt.neu.edu.cn/jwapp/sys/cjzhcxapp/api/wdcj/queryPjxfjd.do"
DETAILS_URL = "https://jwxt.neu.edu.cn/jwapp/sys/cjzhcxapp/api/wdcj/details.do"

HEADERS = {
    "Accept": "application/json, text/plain, */*",
    "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8",
    "Referer": "https://jwxt.neu.edu.cn/jwapp/sys/cjzhcxapp/*default/index.do",
    "X-Requested-With": "XMLHttpRequest",
}
```

## 数据模型

### CourseScore (dataclass)

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `name` | str | KCM | 课程名称 |
| `code` | str | KCH | 课程号 |
| `score` | float | XSZCJ | 成绩（数字） |
| `gpa` | float | JD | **系统返回的单科绩点** |
| `credit` | float | XF | 学分 |
| `term` | str | XNXQDM | 学期代码 |
| `course_type` | str | KCXZDM_DISPLAY | 课程性质（必修/选修） |
| `exam_type` | str | KSLXDM_DISPLAY | 考核方式 |
| `is_passed` | bool | SFJG_DISPLAY | 是否及格 |
| `detail_ref` | str | WID | 仅后端缓存和查询使用，不进入浏览器响应或日志 |

### 单科分项成绩

成绩页只在用户点击某门课的成绩数字时查询该课程详情；不会在登录、打开页面或刷新总表时
批量扫描历史课程。已有缓存先显示，在线模式随后查询最新单科详情。`itemScores` 按远端
顺序保存为动态列表，不假设一定存在“平时/期中/期末”，空列表不会覆盖旧缓存。

详情使用独立的 `score-details` 账号缓存，和总成绩 revision、GPA、培养计划及“新成绩”
提示相互隔离。详情 WID 只存在于后端私密缓存。

### TermScores (dataclass)

| 字段 | 类型 | 说明 |
|------|------|------|
| `term_code` | str | 学期代码 |
| `term_name` | str | 学期名称 |
| `courses` | List[CourseScore] | 课程列表 |
| `total_credits` | float | 总学分（property） |
| `gpa` | float | 学期GPA（property，使用系统绩点计算） |

## 外部接口详情

### 获取学期列表

**Endpoint:** `GET /jwapp/sys/cjzhcxapp/modules/wdcj/cxwdcjxnxq.do`

**Headers:**
- Accept: application/json, text/plain, */*
- Referer: https://jwxt.neu.edu.cn/jwapp/sys/cjzhcxapp/*default/index.do
- X-Requested-With: XMLHttpRequest

**Response:**
```json
{
  "code": "0",
  "datas": {
    "cxwdcjxnxq": {
      "rows": [
        {"XNXQDM": "2025-2026-1", "XNXQMC": "2025-2026学年秋季学期"}
      ]
    }
  }
}
```

### 获取成绩

**Endpoint:** `POST /jwapp/sys/cjzhcxapp/modules/wdcj/cxwdcj.do`

**Form Data:**
- XNXQDM: 学期代码（空字符串查不到数据，必须指定学期）
- pageSize: 500
- pageNumber: 1

**Response:**
```json
{
  "code": "0",
  "datas": {
    "cxwdcj": {
      "rows": [
        {
          "KCM": "课程名称",
          "KCH": "课程号",
          "XSZCJ": "85",
          "JD": "3.5",
          "XF": "3.0",
          "XNXQDM": "2025-2026-1",
          "KCXZDM_DISPLAY": "必修",
          "KSLXDM_DISPLAY": "考试",
          "SFJG_DISPLAY": "是"
        }
      ]
    }
  }
}
```

### 获取总绩点

**Endpoint:** `GET /jwapp/sys/cjzhcxapp/api/wdcj/queryPjxfjd.do`

**Response:**
```json
{
  "code": "0",
  "datas": {
    "queryPjxfjd": {
      "ZPJXFJD": "3.8243"
    }
  }
}
```

## 外部接口速查

### CAS 认证
- `POST https://pass.neu.edu.cn/tpass/login` - 登录

### 成绩查询
- `GET /jwapp/sys/cjzhcxapp/modules/wdcj/cxwdcjxnxq.do` - 学期列表
- `POST /jwapp/sys/cjzhcxapp/modules/wdcj/cxwdcj.do` - 成绩列表
- `GET /jwapp/sys/cjzhcxapp/api/wdcj/queryPjxfjd.do` - 总绩点
- `POST /jwapp/sys/cjzhcxapp/api/wdcj/details.do` - 单科分项成绩（表单 WID）

### 培养计划
- `POST /jwapp/sys/byshapp/api/grbg/queryXyzhbx.do` - 学业监测报告

### 实验选课
- `POST /jwapp/sys/syxkapp/api/xsxk/queryCanSelectedCourses.do` - 课程列表

完整文档内容较多，请参考代码实现或联系维护者获取详细文档。

## 字段映射表

教务系统接口使用拼音缩写作为字段名。

### 常见字段

| 字段 | 含义 |
|------|------|
| KCM | 课程名称 |
| KCH | 课程号 |
| XSZCJ | 学生最终成绩 |
| JD | 绩点 |
| XF | 学分 |
| XNXQDM | 学年学期代码 |
| KCXZDM | 课程性质代码 |

| 02 | 不通过 |
| 03 | 已选课 |
| 04 | 未修读 |

完整映射表请参考代码中的注释。
