# 插件

登录后打开「系统设置 → 插件」，选择「试用学期倒计时」或导入 JSON 文件。核对名称和日期后选择「授权并安装」。插件页显示运行结果，可以停用、重新启用或卸载。每个账号单独保存自己的安装清单。

第 1 版使用声明式工具包。下面的完整示例可保存为 `exam.json`，修改日期和名称即可制作另一个倒计时。`id` 用小写字母开头，可包含数字和短横线，最长 48 个字符。相同 ID 的包需先卸载再安装。

```json
{"format":1,"id":"exam-day","name":"考试倒计时","action":"countdown","date":"2027-01-10"}
```

`countdown` 使用设备当地日期计算相隔的日历天数。插件包仅声明数据，由宿主渲染。此版本支持的动作是 `countdown`。
