# 导出下载与四节活动

“导出下载”是面向可下载、可携带数据的顶级主功能。它不替代成绩页的 GPA 文件、考试页的
ICS 或日志页下载；这些入口仍留在原业务上下文中。新增导出工具时注册为子功能，不再为
每个工具增加一个顶级导航项。

当前首个子功能是“四节活动”，用于汇总当前账号参加的创意节、科普节、科技节和创业节
活动，查看活动详情，并按学期或自定义日期范围打包下载已颁发的证书图片。

## 页面与用户流程

- 顶级入口为 `/export`，以工具卡片展示已安装子功能；四节活动位于
  `/export/festival-activities`，并提供返回“导出下载”的面包屑。
- 子功能由前端导出工具注册表声明稳定 ID、标题、简介、图标、路由、在线可用性和离线
  能力。自动模式曾成功保存活动元数据时，离线可进入只读页面；按需模式没有可读缓存。
- 每次进入页面都先显示中文时间选择卡，用户确认后才进入活动工作区。默认范围为当前
  学年 8 月 31 日至次年 8 月 30 日：当前日期早于当年 8 月 31 日时，起始年取上一年；
  首尾日期均包含。日期输入和显示统一使用 `YYYY-MM-DD` 数字格式。用户可在卡片中改为
  其他不超过 370 天的范围。
- 页面提供两种查看模式：
  - **自动读取并存储**：先读取账号隔离缓存并尽快显示，再在后台完整查询四分区和详情；
    新结果通过现有更新提示应用并保存到 `cache.db`。
  - **每次使用按需读取**：每次进入或手动刷新均直接完整查询远端，结果只存在当前页面
    内存，不读取、不写入活动缓存。
- 查看模式是非敏感界面偏好，可使用统一 settings 工具保存。用户选择按需模式并确认后，
  必须删除**当前账号且仅限** `festival-activities/default` 的既有元数据缓存，再开始远端
  读取；不得删除其他账号、成绩等其他资源或该资源以外的 variant。删除失败必须阻止模式
  切换/读取并给出可重试错误，不能只改偏好、静默保留旧缓存或显示成功。切回自动模式时
  从无缓存状态重新建立本账号快照。
- 桌面端使用完整筛选工具栏、统计、活动列表和详情抽屉；手机端首屏只显示等宽的“筛选与
  查看范围”“打包证书”按钮和当前筛选摘要，完整的学年、日期、分区、搜索及五个并列
  查看范围放入底部筛选抽屉，并提供重置和应用。活动使用摘要卡片和全屏详情；日期筛选、
  详情、刷新和证书打包在 320、375、430px 触屏界面同样可达，桌面筛选布局不受影响。

进入工作区后仍可使用学期快捷范围：秋季为当年 9 月 1 日至次年 2 月末，春季为当年
3 月 1 日至 8 月 31 日，首尾日期都包含。快捷项不会覆盖入页时间卡已确认的范围；用户
点击快捷项时才替换起止日期，随后手动编辑则显示为“自定义范围”。

学年选择可以预生成当前学年起始年前 4 年至后 1 年的快捷项，并合并真实活动中发现的
其他学年。较早的 `2021-2022 学年` 等条目只是历史快捷范围，不代表该学年一定存在活动，
也不会改变默认值；每次进入的默认选择仍严格根据当天日期计算当前学年。

活动按详情中的开始日期进入筛选结果。没有可解析时间的记录仍保留在“全部/时间未知”
视图并显示警告，但不自动归入学期，也不进入日期范围证书包。

列表快捷视图彼此并列：“日期范围内”应用当前起止日期；“全部”“时间未知”“有证书”
和“有奖”都从全部记录中筛选，不与日期范围叠加。“有证书”以远端明确提供证书入口为准；
“有奖”只匹配获奖字段中包含“奖”的记录，非空但不表示奖项的普通备注不算。无论当前
列表使用哪个快捷视图，顶部统计和证书包内容始终只按日期范围计算。

## 数据来源与解析边界

数据来自 `cxcy.neu.edu.cn` 的四节活动系统。后端只访问代码白名单中的参与列表、分页、
活动详情和证书路径：

1. 分页读取创意节、科普节、科技节、创业节四个分区的本人参与记录；
2. 以分区和远端活动/报名标识组成稳定键并去重；
3. 逐项读取详情页，补齐活动时间、时长、地点、部门、报名时间、注意事项和简介；
4. 将简介转换为纯文本，远端 HTML 不传给浏览器；
5. 单条详情缺字段时保留其余记录并返回解析警告，不以一条异常丢弃整次查询结果。

活动契约还包含名称、分区、队伍名、活动状态、类别、获奖名次、签到签退和证书可用性。
远端证书 URL 是私密下载引用。自动模式可在账号级私密缓存中保存受控引用供元数据状态
展示，但任何公开 API 都必须剔除 URL；按需模式不持久化引用。证书打包不信任任何缓存
引用，而是重新抓取并验证。URL 不返回浏览器、不写日志。

## 认证与网络

`NEUAuthClient.request_service("cxcy", ...)` 是 cxcy 的唯一请求入口。service 名、主机、
CAS 回调和允许路径均由代码固定，调用者不能提供任意主机。请求继续使用当前认证客户端
的共享 `requests.Session` 和 `AuthSessionManager` 远端互斥边界，不创建第二套会话、锁
或恢复状态。

cxcy 与教务系统共享用户的 NEU CAS 身份，但拥有独立业务 Cookie。首次访问会完成受控
CAS 跳转；重定向链最终落在 cxcy 即视为业务会话建立成功，最终仍停留在认证页面才视为
登录过期，并最多恢复、重试一次。登出、账号切换或 `identity_epoch` 变化会使已建立的
cxcy 服务会话失效。

即使用户通过 WebVPN 扫码或短信登录，cxcy 请求也直接访问其公网业务域名，不转换为
WebVPN URL。这样只复用 CAS 身份，不把 cxcy 的页面路径误写成教务 WebVPN 路径。

## 缓存、按需查询与离线边界

`festival-activities` 是账号级、可重建、JSON 类型缓存，只服务“自动读取并存储”模式：

| 属性 | 值 |
|---|---|
| variant | `default` |
| freshness | 30 分钟 |
| 离线读取 | 允许，仅活动元数据和已抓取详情 |
| 资源依赖 | 无 |
| 稳定键 | 分区 + 远端活动/报名标识 |
| canonicalization | 稳定排序；移除证书 URL 临时时间戳及本地计算时间 |

自动模式只通过 `CacheRegistry`、`CacheStore` 和 `CacheCoordinator` 读写；cache-only 首屏、
后台更新、手动刷新、single-flight、revision、identity epoch fencing 和事件提示沿用共享
规则。按需模式绕过上述缓存读写，直接通过 `AuthSessionManager` 远端互斥查询；不得提交
refresh job，也不得把结果旁路写入文件、SQLite、localStorage 或 IndexedDB。进入按需模式
前执行一次账号隔离的精确删除：删除键固定为当前身份 epoch 对应账号、资源
`festival-activities`、variant `default`；删除与身份校验处于同一受控边界，不能用全账号
清理代替。删除完成后离线能力立即重新计算；失败时保留原模式和缓存，并向用户明确报错。

离线状态只以兼容的账号缓存判定可用。离线时可查看自动模式保存的活动元数据与详情，
但不能后台更新、按需读取或打包证书。若本账号没有缓存，导出总览仍显示四节活动卡片，
但禁用并说明原因。证书图片和 ZIP 在任何模式下都不是缓存。

## API 契约

| 方法和路径 | 用途 |
|---|---|
| `GET /api/export/festival-activities/cache` | 自动模式读取账号缓存和元数据，不触发远端认证 |
| `DELETE /api/export/festival-activities/cache` | 关闭自动存储时精确删除当前账号活动缓存；与同资源刷新任务协调 |
| `POST /api/cache/refresh/festival-activities` | 自动模式提交或复用后台刷新 job |
| `GET /api/export/festival-activities` | 按需模式当次直连抓取；公开响应不含证书 URL，且不写缓存 |
| `GET /api/offline/festival-activities` | 只读自动模式曾保存的兼容缓存 |
| `POST /api/export/festival-activities/certificates/archive` | 按含首尾日期的范围生成并返回 ZIP |

切换到按需模式还必须调用后端提供的受控单资源删除能力。该操作只能作用于当前认证账号的
`festival-activities/default`，成功后再保存模式偏好并发起按需查询；HTTP/存储失败必须在
页面显示，不能降级为仅在前端隐藏缓存。若该资源已有排队或执行中的刷新，删除操作必须
精确取消它或等待其结束后再删除，保证接口成功返回后旧任务不能重新写回缓存。

日期范围最长 370 天。证书打包不接受浏览器提交的活动或证书 URL，也不复用页面查询
结果；后端收到请求后重新完整抓取四个分区及详情，再从该次远端快照筛选日期和证书。
重新抓取失败则停止打包，不能根据页面旧数据声称已经导出“全部证书”。没有已颁发证书
的活动不是失败；范围内零张可下载证书时返回明确的无数据错误。

## 证书包安全与命名

- 只接受 cxcy 白名单证书静态路径：四个分区各自的旧证书目录，以及共享
  `/static/uploads/res/certificate/{id}/{file}` 目录。共享目录中的 `{id}` 只能由受限长度
  的字母、数字、下划线或连字符组成，后面必须恰好一个图片文件层级；扩展名只允许
  PNG、JPEG 或 WebP。拒绝嵌套目录、路径穿越、userinfo、非标准端口及非时间戳类查询
  参数；缓存规范化会移除临时时间戳。下载时还限制重定向目标、证书数量、单图和总大小。
- 下载响应必须同时通过 HTTP 状态、`Content-Type` 和图片签名校验；HTML 登录页和其他
  非图片内容不得写入 ZIP。
- ZIP 条目名为“活动日期_四节分区_活动名称.扩展名”，清理控制字符和路径分隔符并处理
  重名，不包含姓名或学号。
- 部分下载失败时仍返回成功图片，并加入 UTF-8 `下载说明.txt`，只记录活动名和脱敏失败
  原因；响应头分别给出成功、失败数量，界面据此提示“部分成功”。
- ZIP 使用内存/受控临时流构建，响应完成即清理；证书图片和 ZIP 不写入缓存或用户文档，
  不进入日志、测试夹具或发行物。

## 验证重点

- 解析：四分区、分页、空列表、重复记录、缺字段、时间未知、证书有无、页面结构变化、
  返回登录页。
- 认证：直连和 WebVPN 登录后的首次建会话、已有业务 Cookie、CAS 过期恢复、登出和切号。
- 模式协调：自动模式 cache-first/SWR、刷新去重、revision 和离线读取；按需模式进入/刷新
  直接联网且不落盘；切换到按需时只删除当前账号的 `festival-activities/default`，不误删
  其他账号、variant 或资源，删除失败可见且不继续切换；重复点击、快速离页和请求竞态不
  会串用或回写错误模式。
- 打包：日期边界、零证书、部分失败、旧分区目录和共享 `certificate/{id}/{file}` 目录、
  伪图片、越界重定向、非法 ID/嵌套层级/扩展名/query、数量/大小限制、恶意和重复文件名、
  中文下载名，以及打包前重新抓取而不复用页面结果。
- 界面：工具注册表、嵌套路由、每次进入中文时间卡、数字日期格式、8 月 31 日学年边界、
  历史学年快捷项不改变当前默认、“有证书/有奖”跨全部记录的独立筛选语义、模式开关、
  日期联动、首次自动模式 cache miss 持续显示 loading 并提交 refresh、请求竞态、Blob
  错误、离线只读/禁用，
  并覆盖 320×800、375×812、430×932、768px 和桌面宽度。
