# 自动评教

自动评教页对应 `/evaluation`，用于读取当前评教任务、填写单课评价或按统一策略批量提交。
评教是不可轻易撤销的远端写操作；页面不会在打开、选择课程或预览策略时自动提交。

## 操作流程

1. 阅读页面顶部须知并点击“已知晓”。未确认前提交入口不可用。
2. 选择评教任务，查看待评和已评课程。
3. 单课评价时读取该课程的真实指标，逐项选择等级，可填写文本指标。
4. 批量评价时选择待评课程和评分策略。
5. 提交前再次确认评分策略和课程数量。
6. 批量进度逐门展示成功或失败，并允许终止尚未发送的后续提交。

手机端保留任务选择、课程选择、单课详情、策略和批量提交；操作入口与桌面端使用相同提交
函数和禁用状态。

## 评分规则

指标和选项均来自官方当前任务，不在前端写死。内置策略用于预填选择型指标，用户可以在
提交前逐项修改。官方会拦截全部指标完全相同等无效组合，前端也会在可判断时提前提示。

已评课程只提供详情，不重复加入批量提交。批量接口逐门返回结果；部分成功不会被包装成
整体成功。

## 安全与失败处理

- 只接受当前任务返回的课程 ID 和指标 ID。
- 提交前重新校验任务、课程和指标关系。
- 同一时间只允许一个评教确认或提交过程。
- 写请求发出后遇到超时、认证变化或未知响应，不自动重放该课程。
- 批量终止只停止尚未提交的课程，已成功提交的评价不会回滚。
- 日志记录任务和结果状态，不记录账号密码、Cookie 或完整自由文本评价。

## API

| 接口 | 用途 |
|---|---|
| `GET /api/evaluation/cycles` | 当前可用评教学期/轮次 |
| `GET /api/evaluation/tasks` | 任务列表和完成数 |
| `GET /api/evaluation/tasks/{task_id}/courses` | 任务内课程 |
| `GET /api/evaluation/courses/{xspjid}/indicators` | 单课指标和选项 |
| `POST /api/evaluation/submit` | 提交一门课程 |
| `POST /api/evaluation/batch` | 后端批量契约（页面当前逐门反馈） |

领域适配位于 `backend/core/evaluation/api.py`，路由位于
`backend/app/routers/evaluation.py`，页面位于 `frontend/src/pages/EvaluationPage.js`。

## 验证重点

- 须知未确认时不能提交；
- 策略预填和手动修改使用官方真实选项；
- 重复点击不会产生并发写请求；
- 失败或未知响应不会自动重放；
- 320–430px 视口可完成任务选择、课程选择、单课和批量操作。

自动测试必须使用模拟客户端，不能向真实评教系统提交。相关测试见
`backend/tests/test_evaluation_api_contract.py` 和 `frontend/src/pages/EvaluationPage.test.js`。
