# 账号与远程管理

Go 远程部署使用 HTTPS 反向代理。

## 使用入口

远程用户先输入网站访问密码，再使用已准入的 NEU 账号登录。使用默认管理员学号登录后，可直接在「系统设置 → 站点管理」管理账号准入和站点默认主题。管理权限随教务会话生效，退出或会话失效时撤销。普通账号的设置页不显示该入口。旧地址 `/admin` 返回 404。
旧部署升级时，如果没有指定学号，系统按准入记录的创建时间选定第一个仍启用的账号并保存选择。空名单的部署由服务器维护者配置 `NEU_JWXT_ADMIN_ACCOUNT` 后重启服务。
管理页使用与主站一致的设计令牌，按“账号管理 / 站点外观”分区；支持筛选准入名单、添加准入学号、停止运行、停用、移出准入名单和恢复准入，
并在单用户模式显示名额状态。桌面与手机功能一致，危险的停用和移出操作收纳在更多菜单中。
涉及已有账号的变更先展示账号和影响说明，确认后才提交。失败保留错误提示，不将请求发出视为操作成功。

- 停止运行：结束该账号登录和后台任务，仍允许再次登录；保存的任务保持暂停，需手动重新开启。
- 停用或移出准入名单：同时停止运行并禁止再次登录；保留资料，恢复准入后可以继续使用。
- 恢复准入：重新允许登录，不自动启动此前任务。

默认管理员的准入由服务器配置管理。服务器版本检查保留在「系统设置 → 配置项 → 应用版本」。管理员学号登录后可下载对应 Go 发行包，标准 Linux 服务的安装和回退在服务器终端执行。[部署说明](../部署/Go运行包.md#已有-go-服务一键升级与回退)

管理员只看到学号、准入状态及必要账号元数据，不能通过管理员权限读取用户教务资料、密码或会话。
远程单用户模式最多允许一个启用账号；远程多用户模式各账号资料、会话、任务和邮件独立。
账号停止和停用会使旧登录代次失效；后台迟到的结果不能覆盖新会话。选退课结果不明的证据保留，重启不自动重发。

## 初始化与维护

学校账号退出时，撤销旧会话和删除保存的主教务、选课服务登录凭据在同一数据库事务中完成。如果写入失败，这些变更一并回滚，用户可以重试；保存的邮件配置不随退出删除。

普通学校账号退出保留离线缓存。接口调用方显式使用 `POST /api/logout?clear_data=true` 时，会在撤销当前账号会话的同一事务内清除其可重建缓存、缓存事件及当时已有的个人诊断日志；退出操作本身仍可产生新的诊断记录。个人方案、偏好、待核验操作记录以及其他账号的数据不在清理范围内。

Go入口支持`--mode local-single|remote-single|remote-multi`。远程部署配置 `NEU_JWXT_ADMIN_ACCOUNT` 和
`--public-origin https://你的域名`，新数据目录用 `NEU_JWXT_ACCESS_PASSWORD` 初始化网站访问密码。密码长度为8–256字符。
维护者可先使用`--init-only`初始化独立数据目录，无需启动网页或访问学校。
初始化后可移除密码环境变量；数据库只保存加盐scrypt结果。

忘记网站访问密码时在服务器上设置新密码环境变量并运行 `--reset-site-password access`。密码替换会撤销旧的网站访问会话，网站访问会话最长 7 天。
网站密码登录按来源限流。反向代理仅信任 `--trusted-proxies` 明确列出的地址段，默认只信任本机回环地址。
容器部署可用`--container`配合远程模式监听所有容器网卡；公网TLS仍由反向代理负责。
部署模式与数据目录绑定，不能仅修改启动参数将同一目录改成其他模式。

## 当前验证范围

Go测试覆盖两账号隔离、访问门和管理权限分离、撤权、任务暂停、重启、密码替换与代理来源伪造；
前端测试覆盖管理员进入设置后直接读取名单、普通账号不读名单、确认后提交、失败提示和失权后清空名单。后端覆盖旧管理凭据失效、退出后失权和 `/admin` 返回 404。
`node tools/check_admin.cjs` 用合成接口在 320/375/430/768/1024/1440px 核验访问门、站点管理、取消确认、停用、恢复和普通账号隔离，并检查浏览器异常和横向溢出。
