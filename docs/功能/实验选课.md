# 实验选课

## 功能边界

实验选课用于查询当前学期实验课程、必做实验项目及可选实验班，并执行选课或退选。
它是远端写功能，不支持离线模式；所有请求必须复用当前 NEU 登录会话。

主要实现：

- 核心请求与模型：`backend/core/academic/experiment.py`
- HTTP 路由：`backend/app/routers/experiment.py`
- 前端 API：`frontend/src/services/api.js`
- 页面：`frontend/src/pages/ExperimentCoursePage.js`
- 选课结果优先读取 `experiment-courses` 账号缓存；缓存结果先显示，课程和实验班操作数据随后后台刷新。
- 页面刷新使用统一缓存任务入口；读取失败时保留已显示的选课结果，并提供重试，不能把失败解释为零门课程。

## 数据层级

```text
实验课程 ExperimentCourse
  └─ 实验项目 ExperimentProject
       └─ 实验班次 ExperimentRound
```

课程展示必做数量、已选数量和完成状态；顶部“选课结果”直接读取教务系统
`xkjg/queryStudentAllSelectCourseResult.do` 的项目级结果及状态。课程名和课程号优先使用
官方结果任务层字段（项目行缺失时不能显示为人为拼出的课程）；班次展示教师、
容量、周次、星期、节次、地点、选课时间范围、冲突状态和是否可选。已选结果卡片按字段
网格完整显示实验班、教师、周次、星期、节次、地点和选课时间，窄屏时改为单列自然换行。
实验班同时与当前账号同
学期的个人课表缓存批量比较；官方冲突和新鲜课表中的本地硬冲突都会阻止选择，并展示
冲突课程、交集周次和节次。缓存缺失、陈旧或时间信息不完整均返回“待核验”，旧冲突只作提示而不会
错误阻止选择；用户确认后仍可交由教务系统最终校验。

“无课程/无班次”是正常空状态；接口失败、登录失效和数据解析失败不能伪装成空数据。

## API

页面会静默读取账号级教务系统消息缓存，并只识别标题或正文包含“实验选课、实验课程、实验项目、
实验班、实验课”的通知。只有官方标记为未读的消息才弹出；确认后同一登录会话内切换页面不再重复弹出，
并逐条调用教务系统消息中心的官方已读接口同步状态；官方已读成功的消息会同步写回本地
`system-messages` 缓存，避免后台旧快照完成后再次恢复为未读；
提示复用现有更新摘要弹窗样式，不阻塞课程列表；读取失败、
缓存过期或消息为空都不阻断课程列表和选课操作，也不会弹出全局错误提示。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/experiment-courses` | 查询课程；`term` 为空时由后端获取当前学期 |
| GET | `/api/experiment-courses/{task_id}/rounds` | 查询项目可选班次 |
| GET | `/api/experiment-courses/cache` | 读取课程与官方选课结果缓存 |
| POST | `/api/experiment-courses/select` | 选择实验班 |
| POST | `/api/experiment-courses/deselect` | 退选实验班 |

选课/退选参数包含学期、教学任务、项目和班次标识。标识只用于请求，不应写入日志或
由前端自行拼接教务 URL。

缓存接口：

| GET | `/api/offline/experiment-courses` | 离线读取最近一次实验选课快照 |
| POST | `/api/cache/refresh/experiment-courses` | 通过统一缓存任务刷新课程和选课结果 |

## 修改时必须联动

- 修改字段时同步 core 模型、router 返回、`frontend/src/services/api.js` 和桌面/手机页面。
- 选课按钮必须同时检查容量、冲突、选课时间和后端 `can_select`；禁用原因应可见。
- 候选班按可选无冲突、待核验、冲突、满员/不在时间窗排序；可从实验班安全跳转到对应
  学期、周次和星期的个人课表，URL 不携带班次、教师或教室标识。
- 写操作必须防重复点击并二次确认，成功后重新获取课程和项目状态。
- 退选后不能只改前端标签，必须以服务端刷新结果为准。
- 手机端优先展示课程名、完成状态和项目操作；中心、学院、代码等低频字段放到详情。
- 长项目名、时间和地点必须换行，操作按钮不得溢出卡片。
- 登录失效按统一认证流程处理；server 模式还必须通过网站访问网关。

## 测试要求

- 当前学期自动识别、指定学期和空课程。
- 课程/项目/班次字段缺失时的兼容解析。
- 满员、冲突、未到时间、已选和可选状态。
- 选课、重复点击、失败反馈、成功刷新和退选。
- 320px 手机端课程卡片、项目展开和班次操作。

选课和退选统一使用 `ExperimentCourseMutationRequest`，四个远端标识均为必填、限制长度、
禁止控制字符且拒绝额外字段；缺字段或非法输入由 FastAPI 返回 422。core 不直接 `print`
远端异常或把异常文本返回浏览器，只记录不含账号、标识和响应内容的受控日志。仅官方
`code=0` 后执行 `MUTATION_POLICIES` 声明的缓存失效，其中个人课表只失效
`personal-timetable/term:<操作学期>`；只有操作学期经教务系统确认仍为官方当前学期时，
才以账号身份代次保护的单飞任务在后台重建。历史学期选退不得创建个人课表缓存；失败不得
改变本地状态。
