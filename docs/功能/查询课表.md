# 查询课表

“查询课表”把教务系统 `kbapp` 中分散的四种入口合并到一个页面：我的课表、班级课表、
教师课表和教室课表。页面默认打开“我的课表”，其余三类通过同级标签切换。

## 用户流程

1. 页面优先识别官方当前学期和当前教学周。当前周有课时直接显示本周；假期或无课周会
   检查紧邻的下一学期，已发布则显示下一学期课表，否则显示当前学期完整课表。页面会
   说明自动选择原因，用户仍可手动切换。
2. “我的课表”直接读取当前学生的开课校区；其余三类先按代码或名称搜索班级、教师或
   教室，再选择目标。
3. 选择校区，并在“周课表 / 学期课表”之间切换。存在多个开课校区时默认提供“全部校区”，
   避免跨南湖、浑南上课时只读取首个校区而漏课；周课表默认定位教务系统标记的当前教学周。
4. 教学周按周日到周六计算和展示；1024px 及以上桌面端固定使用“节次轴 + 七个等分日期列”，
   不因同时间课程数量扩大整张表，也不提供横向滚动。各节次行不使用固定高度，而是根据该行
   涉及课程的完整名称、周次、地点、教师/班级和类型计算最低所需高度；单节长课程会获得足够
   空间，跨多节的短课程则共享已有行高，不会简单按节数成倍拉长。课程卡不使用左侧色条、连续
   轨道或额外背景板，同期课程仅通过折叠位置、轻微重叠和阴影表达关联。同一时段默认展开第一
   门课程：它从自身起点一直铺到同期时段底部，其余课程按原顺序压缩为“课程名 + 周次”折叠卡
   覆盖在底部。鼠标悬停或键盘聚焦下层课程时，该课程从当前位置铺到底部；上方课程收起，下方
   折叠卡继续叠放在其底部，且展开内容会为这些折叠卡预留空间，不会被遮住。
   普通课程与同期课程使用相同的左右边界；折叠卡高度按各自完整课程名的实际换行数独立计算，
   不使用省略号，也不会为了统一高度把短标题卡无意义拉高。
   同期课程的默认层级不采用教务接口返回顺序：开始节次更早的课程优先；开始节次相同时，结束
   节次更晚、覆盖范围更大的课程作为默认底层，避免把第1–2节课程视觉上误画成持续到第4节。
   鼠标命中由稳定的时段容器按当前卡片区域判断，不依赖正在移动的卡片本身，因此动画不会使
   静止的鼠标反复丢失悬停。点击展开或折叠卡都直接进入完整详情。每项仍保留
   自己的节次和无障碍说明；无法容纳的项目通过“另 N 项”
   打开完整课程列表。课程色使用高对比底色和边框编码。更窄视口直接使用手机
   按日列表，不把七天表格压缩成不可读窄列。
   “今天”只会在当前学期的当前教学周（或当前学期的全学期视图）显示；正在上课且周次、星期、
   起止时间都匹配的课程使用低强度动态标记，系统减少动态效果时自动停用动画。
   手机端教学周使用横向时间轴，原生滚动结束后吸附并选择居中的周次；顶部信息块负责打开
   学期与校区筛选，旁侧“周 / 总”开关直接切换周课表和全学期课表，不再重复放置第二个漏斗
   按钮。首次进入当前周自动定位今天，用户手动选择某个星期后，前后切换教学周仍保留该星期。
5. 单课程卡固定突出课程名、地点、教师或班级上下文以及“必修/选修 · 考试/考查 · 节次”；
   全学期视图还会直接显示
   上课周次。同一星期和节次但周次不相交的课程会分别显示且不标记冲突；只有周次与节次
   同时重叠才显示“同周时间冲突”。教师、班级、课程代码、成绩类型和官方完整安排放入详情。
   未安排节次课程和集中实践课程单独列出。
6. 当前学期“我的课表”遵循统一缓存流程：先展示本地缓存并在后台核验；检测到变化且页面可见
   时询问是否更新当前显示，页面不可见时由缓存直接更新，下次进入读取新版本。页面不再额外显示
   “已先展示本地课表”横幅。当前账号的当前学期课表同时保留在身份隔离的前端内存层，路由切换
   后返回课表页会首帧恢复原课表、校区、周次和显示范围，再静默读取 SQLite 并核验版本，不重新
   显示整页骨架。刷新按钮悬停显示最后保存时间，手动刷新会立即获取并应用最新课表。
7. 班级、教师和教室课表提供“冲突检测”开关。开启后，将当前预览的全部已排课程一次性与
   官方实时读取的同学期“我的课表”比较，不使用可能滞后的个人课表缓存作为预览检测基准；
   实时读取失败时不展示缓存生成的冲突。只有学期相同、星期相同、周次相交且节次重叠才标红课程名称。
   同一课程不视为冲突：优先按课程代码识别，代码缺失时只使用规范化后的完整课程名兜底。
   鼠标悬停红色课程时在相邻浮层中展示冲突的个人课程、重叠周次和节次；周次或时间数据
   不完整时保持待确认，不伪装成确定冲突。
8. 选课工作台复用同一课表组件的 `selection` 展示模式。该模式保留四类课表、课程详情、
   星期顺序、同期课程簇堆叠与冲突语义，但使用紧凑节次基础高度，课程卡只显示课程名称与
   待选/已选/预览状态。同期课程继续采用查询课表相同的“默认展开最长课程、悬停切换展开项、
   其余课程上下折叠”交互；只有课程簇确实需要容纳更多标题时才增高涉及的节次。
   调用方可以叠加候选课程、传入冲突结果，并接收用户点击的星期和节次，用于反查可选课程；
   普通“查询课表”页面继续使用内容自适应高度，不受该模式影响。

三类全校查询不再先展示教务系统中数百或上千页的对象表格，而是使用远程关键词搜索
选择器。班级代码/名称、教工号/姓名、教室代码/名称都可以直接检索；中文关键词固定映射
到名称字段，代码型关键词固定映射到 `CODE`，不再使用会被官方模型忽略的
`_commonFilter`。教师姓名以官方实际使用的 `XM` 为首选，并兼容部分响应中的 `JSMC`；
每次远端搜索都会核对返回对象是否确实命中关键词，防止 EMap 静默忽略无效字段后把普通
第一页误当成搜索结果。纯代码关键词在首选字段无结果时会在名称/代码字段之间执行一次受控回退，
兼容教室名形如 `A101` 的情况。候选列表滚动到底部会继续读取下一页，失败页可原页重试。

筛选弹窗内可直接切换学期；分类筛选同样在所选学期的远端完整名单上执行，而不是只过滤
浏览器已经加载的候选：班级支持年级、
学院、专业、方向、校区和排课状态；教师支持单位、职称、性别、外聘与排课状态；教室支持
校区、教学楼、楼层、类型、管理单位、使用范围、实验中心、完整容量范围和排课状态。后端只接受这些
产品字段，并映射到固定的教务模型字段，前端不能提交任意字段名。全部分类控件始终显示；
尚未加载到选项、当前父级条件不足或当前关联组合没有可用值时，控件以禁用状态保留，待
目录加载或上级条件变化后自动恢复。筛选弹窗会独立分页扫描
该学期的完整官方对象列表并生成分类目录，因此未出现在当前 50 条搜索结果中的学院、专业、
楼宇等分类也可以直接选择；弹窗立即打开，目录在后台加载，失败时可单独重试，不影响已经
加载的搜索结果。三个标签在当前页面会话中分别保留关键词、筛选、完整分类目录、滚动加载
结果和最近选择，不写入本地持久化。切换学期会清除仅对旧学期有效的对象、结果和分类目录，
但保留用户已设置的关键词与筛选值，并用新学期数据重新查询。

分类目录除独立选项外还保留不含具体班级、教师或教室标识的匿名关联组合。关联筛选是有方向
的：学院约束专业、专业约束方向，校区约束教学楼、教学楼约束楼层，但低级选项不会反向锁死年级、学院等高级
选项。用户修改高级条件后，仍然有效的下级值予以保留，只自动清除冲突或不存在的值；必须
先选父级的下拉框会禁用并
明确提示“请先选择××”。请求和应用筛选时始终使用 raw code，不使用显示名称。
年级筛选选项和已加载的班级查询结果统一按最近年级优先排列；滚动加载新页后会对当前已加载
结果重新排序，不让旧年级长期占据列表顶部。

查询对象输入框仍以远程搜索为主。没有输入关键词时，当前筛选命中的对象也会作为卡片列表
显示在课表区域，支持继续分页加载；点击任一卡片后该区域原位切换为对应课表。筛选弹窗内
同步展示相同的匹配对象，用户可以在筛选时直接选择班级、教师或教室，无需关闭弹窗后再到
查询对象下拉框重复选择。

## 官方行为核对

本功能在实现前通过已登录的官方页面实际核对了以下行为；调查只读取页面和请求资源，
没有执行课表确认等写操作：

- 我的课表：学期切换、全部校区/具体校区、学期课表、周课表、未安排课程、
  集中实践课程。
- 班级列表：代码、名称、年级、学院、专业、专业方向、校区及是否存在排课等信息。
- 教师列表：教工号、教师名、所在单位、职称、性别、是否外聘及是否存在排课等信息。
- 教室列表：代码、名称、校区、教学楼、楼层、类型、管理单位、使用范围、实验中心、
  容量及是否存在排课等信息。

官方列表模型的真实 action 分别为：

| 模式 | action | 课表类型 `KBLX` |
|---|---|---:|
| 教室 | `jslb` | `01` |
| 教师 | `lslb` | `02` |
| 班级 | `bjlb` | `05` |

官方课表组件已经返回结构化的星期、起止节次、起止时间、`cellDetail`、`titleDetail`、
`tags`、未排课程和实践课程。本项目直接使用这些结构化字段，只有课程标识缺失时才生成
稳定摘要 ID，不复刻官方页面依赖字符串位置的脆弱解析。

周次优先读取官方 `weeks`、`weekList` 等结构化字段。`weeksAndTeachers` 或详情行属于混合
文本时，只提取明确以“周”结尾的周次子句，楼号、教室号、“第1实验班”和“第1-2节”等
数字不得进入周次集合。周次解析规则升级会提升 `personal-timetable` schema；不兼容旧缓存
在首次请求时必须等待刷新，不能先返回可能含错误周次的旧数据。

参考项目 `PeterPtroc/neu-jwxt-to-wakeup` 仅覆盖个人课表 CSV 导出，并通过
`titleDetail` 空格位置猜测周次和地点。它帮助确认了 `arrangedList`、`dayOfWeek`、
`beginSection` 和 `endSection` 的含义，但本项目没有复制其多校区遗漏、教师截断和周次
字符串解析逻辑。

## 后端接口

所有接口均为只读，且受网站访问密码（server 模式）和 NEU 登录双层保护。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/timetable/terms` | 获取可用学期和当前学期 |
| `GET` | `/api/timetable/personal` | 按学期读取或刷新当前账号的完整个人课表缓存 |
| `POST` | `/api/timetable/targets/search` | 分页搜索班级、教师或教室 |
| `POST` | `/api/timetable/targets/filter-options` | 读取指定学期和查询模式的完整分类目录 |
| `POST` | `/api/timetable/context` | 获取目标在指定学期、校区下的教学周和节次 |
| `POST` | `/api/timetable/schedule` | 获取学期或指定周的课表 |
| `POST` | `/api/schedule/conflicts/check` | 批量比较候选时间与个人课表，返回冲突、无冲突或无法确认 |

搜索与课表参数放在 POST 请求体，避免教师姓名、班级或教室出现在浏览器历史和反向代理
查询串。输入只接受固定模式、受限长度的学期/目标/校区代码、1–30 周和最多 50 条分页；
前端不能传任意官方 URL 或 action。

Core 始终把原始 `jwxt.neu.edu.cn` URL 交给 `NEUAuthClient`，由共享
`AuthSessionManager` 串行使用当前 Session，并由认证客户端统一处理直连/WebVPN URL、
Referer、Cookie 和登录恢复。官方响应不会原样穿透到浏览器；未知字段、调试信息和潜在
内部标识默认丢弃。

学期目录在当前认证客户端内保留 10 分钟的短期内存快照。命中时不占用远端 Session
互斥锁，页面并发进入也只复用一条学期请求，避免被个人课表刷新或完整筛选目录扫描长期
阻塞。该快照不写入 `cache.db`，切换账号后随认证客户端释放；首次读取和过期刷新仍在
统一远端会话边界内完成。

## 缓存与离线边界

当前版本只把“当前账号的官方当前学期个人课表”注册为项目缓存资源：

- 资源名为 `personal-timetable`，按账号隔离，variant 固定对应官方标记的当前学期
  `term:<当前学期代码>`；缓存完整学期课程、教学周、校区和节次，当前学期内切周与切校区
  不重复访问教务系统。缓存入口会重新核对官方当前学期，历史学期不能绕过前端建立 variant。
- 历史学期个人课表和“下一学期是否已发布”的自动探测均走实时 `/context`、`/schedule`
  查询，不写入 `cache.db`；切换其周次或校区时按需重新查询。
- revision 使用稳定课次 `meeting_id` 和规范化业务字段；远端顺序、抓取时间不制造变化。
- 缓存刷新复用 CacheCoordinator 的 single-flight、共享 Session 互斥和身份 epoch fencing。
- 本地个人课表读取不持有远端 Session 互斥锁；仅学期目录首次获取和后台刷新任务进入远端锁，
  因而其他教务请求或正在执行的课表刷新不会阻塞已有课表的首屏显示。
- 实验选退成功会失效对应学期的旧 variant，但只有操作学期仍是官方当前学期时才自动重建；
  历史学期操作不得创建或刷新个人课表缓存。
- 班级、教师、教室属于任意全校查询结果，不长期保存到 `cache.db` 或浏览器存储。
- 全校查询的分类目录只在当前认证客户端进程内缓存 30 分钟，只包含分类代码、显示名称和
  匿名分类关联组合；
  不保存完整班级、教师、教室名单，切换账号后随认证客户端一起释放。
- 当前离线模式仍隐藏“查询课表”；课表缓存用于在线页面和跨功能冲突判断，不在本轮开放
  离线入口，也不使用 `localStorage` 保存课程。

## 响应与错误语义

- 合法课表没有课程：返回空课程列表，页面显示“当前条件下暂无已排课课程”。
- 三类全校课表未选择对象：本地返回 `422`，不向教务系统发请求。
- 登录失效：沿用全局 `401` 静默恢复/重新登录流程。
- 官方拒绝、网络失败或响应结构变化：返回脱敏 `502` 和错误编号，不伪装成空课表，也不
  回传官方原始响应或完整 URL。

## 验收重点

- 默认标签是我的课表；四类标签、学期、校区、周/学期切换和刷新共用同一请求契约。
- 快速切标签、学期、查询目标、校区或周次时，旧课表立即退出展示，迟到响应不能覆盖当前选择；
  学期切换会清除上一学期的对象与结果，但保留每个模式的关键词和筛选值。
- 桌面同时间课程显示为课程簇且不会扩大日期列；手机按天列表可查看全部详情；键盘可聚焦
  课程簇中的每一项并打开详情。
- 320、375、430px 使用按日列表；1024、1280、1440px 完整显示周日到周六，页面和课表均
  无横向溢出。
- 测试夹具只使用合成课程、教师、班级和教室，不包含真实学号、姓名、Cookie 或 `_yhz`。
