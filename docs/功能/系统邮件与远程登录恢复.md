# 系统邮件与远程登录恢复

主教务已登录、目标服务使用 WebVPN 时，如果当前账号已有该服务的验证码或短信验证，选课或创院页面可以继续原流程。创院不会接管选课验证，选课也只接续自己的验证。状态检查不会返回验证码图片，也不会为已匹配的待验证流程再次访问学校。

在同一浏览器换号后，新账号不能读取原账号的子服务验证码，也不能继续原账号的扫码。仅保留浏览器的验证流程标识、没有对应的学校登录会话时，同样不能读取或继续。

如果另一个浏览器已经在为同一个已知账号进行 WebVPN 验证，新浏览器不能再开一条验证流程。请回到原浏览器继续或取消验证，或等它过期。

同一账号已有后台验证时，手动启动扫码或密码登录不会替换这次验证。请继续原流程，或先取消再重新开始。

如果旧验证已超过有效期和宽限期，再次开始验证时会清理旧记录，不必先回主教务页面刷新状态。

使用 WebVPN 的选课或创院只读查询确认登录过期、且当前账号已保存密码时，工具箱可自动开始该服务的验证。学校要求短信验证时，需要用户继续当前流程并明确发送短信，后台不会代发。完成后保留主教务登录，可重新读取该服务的数据。

选课或创院使用直连线路时，如果只读查询在目标服务登录入口收到明确的 401，且当前账号已保存密码，工具箱会尝试恢复该服务，成功后重新读取一次。如果登录入口能打开，但业务查询返回 401，工具箱先不用密码刷新会话；再次读取仍返回 401 且不是限流时，才尝试密码恢复。同一账号运行期间，同一服务一分钟内不会重复启动密码恢复。未保存密码时不尝试；提交选课等写操作不会借此重发。

工具箱自动核验已保存的主教务会话时，若学校服务不可达或 WebVPN 请求超时，会等待重试，不发送已保存的密码。若核验发现账号不匹配或 WebVPN 无法确认账号身份，则需要手动恢复，不会自动覆盖当前会话。

例如，直连身份接口返回业务码 `503` 和“登录服务维护中”时，工具箱等待重试；返回 `401` 或明确提示“请重新登录”时，才按登录失效处理。

选课或创新平台在子服务认证跳转时返回限流（429）或服务器错误（5xx），不代表主账号退出。遇到限流时，工具箱会暂停该账号对相应服务的认证请求 30 至 300 秒；等待期间反复点击不会再向学校发送请求。遇到服务器错误可稍后重试，不必重新登录。

旧版进程级设置可通过[旧版资料导入](../部署/旧版资料导入.md)显式分配到新版账号，
SMTP 密码加密接续，旧恢复链接和邮件队列不复用，迁移不会主动发送邮件。

系统邮件和远程认证恢复是两个进程级基础服务。成绩追踪与自动选课分别调用它们，不再通过
彼此转发通知或登录状态。

Go重构分支已接通邮件设置读取/保存及测试邮件，沿用现有设置页。多用户模式中邮件配置与凭据按
工具箱账号隔离，每个用户仅能查看和修改自己的邮件通道；本地单用户同样使用当前账号配置。
完整配置存入加密存储，密码仍不回传，留空保留、明确清除才删除。测试发送独立于学校请求，支持
SSL/TLS、强制STARTTLS和明确选择的无加密连接，以及PLAIN/LOGIN认证；STARTTLS失败不降级明文。
后台outbox已接通持久保存、发送、失败重试与去重；选课任务状态/轮次/登录失效/策略更新通知已接通，
需另外开启本轮通知偏好。任务内人数阈值和结束前开课风险提醒已接通；成绩通知及认证恢复链接
已接通。真实学校与SMTP端到端验收仍待完成。

## 配置入口

Go版已接通恢复站点地址和有效期的读取、保存及账号隔离。远程模式接受HTTPS根地址；本机调试
允许回环HTTP地址。省略字段保留原值，有效期为1–168小时整数。地址变化会轮换恢复配置版本，
旧链接即使后来改回原地址也不复活；修改时长不延长既有链接。
Go版现已接通签名上下文、邮件发送时链接组装、扫码和短信恢复接口。队列只保存上下文ID，
不保存签名URL；排队期间链接失效则不发送。新通知会使用新上下文ID重新去重。
访问恢复页面无需网站密码，只能操作该链接绑定的账号和认证目标；成功也不获得普通账号登录Cookie。
已有同账号同目标短信挑战直接续接，短信已验证但业务会话待建立时继续原会话，不重新发短信。
图形验证码输入错误时，如果学校返回新图片，页面会显示新图并继续同一短信认证流程；
刷新恢复页也能读取这张新图，不会自动重发短信，内部流程标识和账号不会随错误响应返回。
JWXK恢复在已有主Runtime时只合并网关，不替换主教务线路；主Runtime不存在时已支持独立选课任务
会话。此会话只允许WebVPN选课请求，主教务仍显示未登录，不授予成绩、科研等其他服务访问能力。
独立会话按账号加密保存；重启先核验子服务Cookie再运行任务，退出或停用后不随重启复活。
之后恢复主登录会保留已恢复的选课网关，维持用户所用主教务线路。
成功发布前再次校验链接、账号代次和原Runtime；恢复地址修改与发布共用账号登录锁。
一次性消费发生在会话发布前；若随后持久化失败，该链接仍保持失效，需重新发起恢复。

在“系统设置”中维护：

- “系统邮件”：SMTP 服务器、端口、安全方式、用户名、密码或授权码、发件地址和收件地址；
- “远程登录恢复”：邮件收件人能够访问的工具箱站点根地址，以及恢复链接有效期（默认 3 小时，可设为 1–168 小时的整数）。

系统邮件配置用于成绩、选课和认证恢复通知。保存后的 SMTP 密码不会回传前端；留空保存会保留
原密码，只有明确清除时才删除。测试邮件只验证 SMTP 通道，不触发成绩检查、JWXK 请求或认证恢复。

相关本地 API：

| 方法和路径 | 请求/响应 |
|---|---|
| `GET /api/system-settings/mail` | 返回 SMTP 非秘密字段和 `smtp_password_configured` |
| `PUT /api/system-settings/mail` | 保存 SMTP 配置；可传 `clear_smtp_password=true` |
| `POST /api/system-settings/mail/test` | 立即发送一封系统测试邮件 |
| `GET /api/system-settings/auth-recovery` | 返回 `public_base_url` 和 `link_ttl_hours` |
| `PUT /api/system-settings/auth-recovery` | 保存站点地址和有效期；省略字段保持原值 |

## 邮件可靠队列

Go版使用SQLite邮件队列，同一账号会话代次、业务来源和事件键只入队一次。程序重启后恢复待发
消息；账号主动退出、停用或移出准入名单后，旧代次的待发消息失效，不随重新登录复活。
不同业务来源可独立取消。后台最多并行处理两个账号，同一账号串行发送，不占用教务请求槽。
失败按1、2、4分钟逐步退避，最长64分钟；成功后清除正文并保留去重记录。中断后超过一分钟的
发送占用可被接管；重试沿用相同Message-ID。SMTP确认丢失仍可能造成重复收件，不能保证邮件端恰好一次。

`backend/core/notifications/mail.py` 中的 `SystemMailService` 是全系统唯一发送器：

- `system_mail_config.json` 保存 SMTP 配置；
- `system_mail_outbox.json` 保存待发送邮件、失败次数和脱敏错误类型；
- 后台发送线程失败后保留消息并重试，不占用教务远端 Session；
- `grade_tracking` 与 `course_selection` 使用独立 source 和去重键，可分别统计待发送数量；
- 认证恢复邮件只保存模板与上下文 ID，发送时才生成签名 URL。

成绩追踪关闭、账号退出或任务状态变化时，只删除对应业务明确失效的消息，不应清空其他业务来源。
`clear_data=true` 会清空 outbox，但保留用户明确保存的 SMTP 配置。

## 一次性恢复流程

`backend/core/auth/recovery.py` 中的 `RemoteAuthRecoveryService` 保存恢复上下文，并提供
`/auth-recovery/<token>` 页面。每个上下文绑定：

- 账号与业务来源；
- `primary` 或 `jwxk` 目标；
- 通知去重键、创建时间、固定到期时间 `expires_at` 和状态；
- 签名 token 的哈希。

如果后台保存账密已经进入同目标短信挑战，页面直接显示学校实时图形验证码；否则先创建微信
二维码。短信只能由用户点击发送或重发，验证码也只能由用户提交。完整 API 见
[WebVPN 校外访问](WebVPN校外访问.md)。

`primary` 恢复成功后原子接管主 JWXT Session。`jwxk` 恢复成功后只合并 WebVPN 网关与 JWXK
子会话；主 JWXT 线路存在时不替换它，主会话暂时不存在时仅保存自动任务专用的 JWXK 候选。
已经发出的选课、退课、撤回或投权请求仍只核验结果，不因登录恢复自动重放。

## 安全与生命周期

- 明文 token、Cookie、密码、图形验证码、短信验证码和完整 CAS 表单不写入配置、状态、outbox 或日志；
- 访问日志把 `/auth-recovery/` 和 `/api/auth-recovery/` 的 token 段替换为 `<redacted>`；
- Linux 网站访问网关只放行新的 token-scoped 恢复 API，其他个人数据 API 仍需网站访问密码；
- 成功、取消、主动退出、清除数据、切换账号或修改恢复站点地址会使相关上下文失效；
- 有效期从上下文创建时计时，修改时长只影响新链接；刷新页面、重开二维码和服务重启均不续期。
  升级前没有到期字段的链接按原创建时间加 3 小时补齐，时间字段损坏时直接失效；
- 到期后所有恢复 API 拒绝操作并清理对应内存 Flow，认证结果在到期后返回时也不能提交。
  邮件正文显示北京时间截止时间；排队期间已过期的恢复邮件不再发送，后续业务重新请求通知时生成新链接；
- 服务停止会取消内存 Flow。服务重启后未到期链接仍可重新开始二维码登录，但不能续接旧验证码；
- 校园网拒绝 WebVPN 时不创建验证码 Flow，只发送切换“校内直连”的说明；
- 恢复历史有界保存，活动链接不因终态历史清理被误删。

旧 `/grade-tracking/recovery/<token>` 页面、`/api/grade-tracking/recovery/*` 和
`/api/grade-tracking/test-email` 已删除，不提供重定向或兼容。升级时会自动迁移旧 SMTP、
`site_url` 和普通待发邮件；包含旧恢复路径的待发邮件会被丢弃。
