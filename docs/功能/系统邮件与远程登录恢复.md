# 系统邮件与远程登录恢复

系统邮件和远程认证恢复是两个进程级基础服务。成绩追踪与自动选课分别调用它们，不再通过
彼此转发通知或登录状态。

## 配置入口

在“系统设置”中维护：

- “系统邮件”：SMTP 服务器、端口、安全方式、用户名、密码或授权码、发件地址和收件地址；
- “远程登录恢复”：邮件收件人能够访问的工具箱站点根地址，以及恢复链接有效期（默认 3 小时，可设为 1–168 小时的整数）。

系统邮件配置用于成绩、选课和认证恢复通知。保存后的 SMTP 密码不会回传前端；留空保存会保留
原密码，只有明确清除时才删除。测试邮件只验证 SMTP 通道，不触发成绩检查、JWXK 请求或认证恢复。

相关本地 API：

| 方法和路径 | 请求/响应 |
|---|---|
| `GET /api/system-settings/mail` | 返回 SMTP 非秘密字段和 `smtp_password_configured` |
| `PUT /api/system-settings/mail` | 保存 SMTP 配置；可传 `clear_smtp_password=true` |
| `POST /api/system-settings/mail/test` | 立即发送一封系统测试邮件 |
| `GET /api/system-settings/auth-recovery` | 返回 `public_base_url` 和 `link_ttl_hours` |
| `PUT /api/system-settings/auth-recovery` | 保存站点地址和有效期；省略字段保持原值 |

## 邮件可靠队列

`backend/core/notifications/mail.py` 中的 `SystemMailService` 是全系统唯一发送器：

- `system_mail_config.json` 保存 SMTP 配置；
- `system_mail_outbox.json` 保存待发送邮件、失败次数和脱敏错误类型；
- 后台发送线程失败后保留消息并重试，不占用教务远端 Session；
- `grade_tracking` 与 `course_selection` 使用独立 source 和去重键，可分别统计待发送数量；
- 认证恢复邮件只保存模板与上下文 ID，发送时才生成签名 URL。

成绩追踪关闭、账号退出或任务状态变化时，只删除对应业务明确失效的消息，不应清空其他业务来源。
`clear_data=true` 会清空 outbox，但保留用户明确保存的 SMTP 配置。

## 一次性恢复流程

`backend/core/auth/recovery.py` 中的 `RemoteAuthRecoveryService` 保存恢复上下文，并提供
`/auth-recovery/<token>` 页面。每个上下文绑定：

- 账号与业务来源；
- `primary` 或 `jwxk` 目标；
- 通知去重键、创建时间、固定到期时间 `expires_at` 和状态；
- 签名 token 的哈希。

如果后台保存账密已经进入同目标短信挑战，页面直接显示学校实时图形验证码；否则先创建微信
二维码。短信只能由用户点击发送或重发，验证码也只能由用户提交。完整 API 见
[WebVPN 校外访问](WebVPN校外访问.md)。

`primary` 恢复成功后原子接管主 JWXT Session。`jwxk` 恢复成功后只合并 WebVPN 网关与 JWXK
子会话；主 JWXT 线路存在时不替换它，主会话暂时不存在时仅保存自动任务专用的 JWXK 候选。
已经发出的选课、退课、撤回或投权请求仍只核验结果，不因登录恢复自动重放。

## 安全与生命周期

- 明文 token、Cookie、密码、图形验证码、短信验证码和完整 CAS 表单不写入配置、状态、outbox 或日志；
- 访问日志把 `/auth-recovery/` 和 `/api/auth-recovery/` 的 token 段替换为 `<redacted>`；
- Linux 网站访问网关只放行新的 token-scoped 恢复 API，其他个人数据 API 仍需网站访问密码；
- 成功、取消、主动退出、清除数据、切换账号或修改恢复站点地址会使相关上下文失效；
- 有效期从上下文创建时计时，修改时长只影响新链接；刷新页面、重开二维码和服务重启均不续期。
  升级前没有到期字段的链接按原创建时间加 3 小时补齐，时间字段损坏时直接失效；
- 到期后所有恢复 API 拒绝操作并清理对应内存 Flow，认证结果在到期后返回时也不能提交。
  邮件正文显示北京时间截止时间；排队期间已过期的恢复邮件不再发送，后续业务重新请求通知时生成新链接；
- 服务停止会取消内存 Flow。服务重启后未到期链接仍可重新开始二维码登录，但不能续接旧验证码；
- 校园网拒绝 WebVPN 时不创建验证码 Flow，只发送切换“校内直连”的说明；
- 恢复历史有界保存，活动链接不因终态历史清理被误删。

旧 `/grade-tracking/recovery/<token>` 页面、`/api/grade-tracking/recovery/*` 和
`/api/grade-tracking/test-email` 已删除，不提供重定向或兼容。升级时会自动迁移旧 SMTP、
`site_url` 和普通待发邮件；包含旧恢复路径的待发邮件会被丢弃。
