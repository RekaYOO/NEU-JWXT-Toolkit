# Go 工具箱 RC32 验收记录

RC32 包含 GPA 计分依据后台补查。接口测试通过设置入口将一个合成账号从旧制切换到新制，使用重复缺失分制的课程和已有分制的课程。最终排队两项任务，分别读取学业报告和缺失课程的分制，两项均写入对应账号的缓存。该测试连续通过五轮。

Windows 成品启动、备份恢复、迁移和升级检查见交付目录的 `verification.json`。Linux 归档通过内容检查。安卓客户端和设备测试包沿用 RC31 签名文件，其中客户端的 31 个网页文件与本版 Windows 包逐字节一致。五个交付文件的 SHA-256 在 `SHA256SUMS` 中。

独立 Linux 主机整机重启、Android 真机 HTTPS 连接及文件保存、旧插件兼容和学校业务仍待验收。早期功能证据和待验场景见 [RC31 验收记录](Go候选包31验收记录.md)。
