# RC34 使用与验收

Android 真机验收请使用 `android-fix-1/client-arm64-debug.apk` 和 `android-fix-1/device-tests-arm64.apk`。这对补充包修复了重叠保存和系统文件选择器不可用时的临时文件清理，有独立的 `android-fix-1/SHA256SUMS`。两个 APK 已通过签名验证，系统文件选择器操作待真机核验。

工具箱版本为 2.2.4。安装前可用同目录的 `SHA256SUMS` 核对下列五个文件的 SHA-256。

| 使用场景 | 文件 | 从哪里开始 |
|---|---|---|
| Windows x86_64 | `NEU-JWXT-Toolkit-2.2.4-windows-amd64-go.zip` | 解压后双击 `启动工具箱.cmd`。升级已有安装前按 `BACKUP.md` 制作备份，旧资料导入见 `IMPORT.md`。 |
| Linux x86_64 | `NEU-JWXT-Toolkit-2.2.4-linux-amd64-go.tar.gz` | 解压后按包内 `README.md` 配置服务和数据目录。 |
| Android ARM64 | `NEU-JWXT-Toolkit-2.2.4-android-arm64-client-debug.apk` | 在测试手机上安装调试客户端，打开后填写已部署服务的 HTTPS 地址。 |
| Android 设备验收 | `android-arm64-device-tests.apk` | 与上面的 ARM64 调试客户端配套使用。 |
| Linux 独立主机验收 | `RC34-linux-acceptance.zip` | 解压后按其中的 `README.md` 核对归档、启动服务并验证整机重启。 |

逐功能验收从同目录的 `Go候选包28验收清单.md` 开始，后续候选包的验证结果按版本号更新，最新为 `Go候选包34验收记录.md`。Windows 成品启动、升级和数据恢复的检查结果在 `verification.json`。

独立 Linux 整机重启、Android 真机 HTTPS 与保存、旧插件兼容、原课表导出格式兼容、开放轮次选课和学校写入流程仍待验收。课表当前提供 JSON 导出。学校证明生成可能消耗打印额度，使用测试账号执行前需取得该项审批。
