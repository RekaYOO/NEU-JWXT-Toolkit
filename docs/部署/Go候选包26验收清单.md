Android 静态检查通过，发现一项 `ApplySharedPref` 警告，位置为切换服务地址时同步清除旧 Cookie 的代码。设备测试需要 Android 7.0 或更高版本的独立测试设备、Android 平台工具，以及设备信任并能访问的 HTTPS 工具箱地址。在发行目录运行以下命令，将最后一条命令中的地址替换为该测试服务地址。

```sh
adb install -r NEU-JWXT-Toolkit-2.2.4-android-arm64-client-debug.apk
adb install -r android-arm64-device-tests.apk
adb shell am instrument -w -e toolboxHttpsOrigin https://toolbox.example.invalid io.github.rekayoo.neujwxt.client.debug.test/androidx.test.runner.AndroidJUnitRunner
```

独立 Linux 验收使用一次性 x86_64 主机，准备 Python 3.12 或更新版本、同一分支源码及本清单对应的完整发行目录。从仓库根目录执行：

```sh
set -eu
release="$PWD/dist/go-release-candidate-26"
(cd "$release" && sha256sum --check SHA256SUMS)
report_dir=$(mktemp -d)
python3 tools/check_go_release.py "$release" --smoke --report "$report_dir/linux-verification.json"
```

核对报告中的 `smoke.platform` 为 `linux`，版本为 `2.2.4`。系统服务首启和整机重启需在该主机单独验收。其他待验项目包括 Android 客户端、真实日历导入、历史大纲附件映射、旧业务插件样例及学校端业务。
