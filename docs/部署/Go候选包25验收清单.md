历史大纲附件：当前页面仅展示名称。旧 Python 和 Go 解析器都从 `FJ` 读取名称，没有向页面提供下载标识。Go 下载接口已通过合成标识的转发与 `no-store` 检查，但列表字段与下载标识的对应关系仍缺少脱敏样例，不能计为可从页面下载。

## 在独立 Linux 主机复验

使用一次性 Linux x86_64 主机、普通用户和 Python 3.12 或更新版本。需准备同一版本的仓库源码（含本分支的检查脚本和主题模板），以及 RC25 原始两份归档、`go-release-manifest.json` 和 `SHA256SUMS`。在仓库根目录运行，发行文件置于以下 `release` 目录；不要重新构建归档代替本次交付物。

```sh
set -eu
release="$PWD/dist/go-release-candidate-25"
(cd "$release" && sha256sum --check SHA256SUMS)
report_dir=$(mktemp -d)
python3 tools/check_go_release.py "$release" --smoke --report "$report_dir/linux-verification.json"
printf 'Linux report: %s\n' "$report_dir/linux-verification.json"
```

成功时核对报告中的 `smoke.platform` 为 `linux`，版本为 `2.2.4`，以及启动、退出、备份恢复与准入重启的结果。脚本仅监听回环地址，使用临时合成数据，不安装系统服务；报告独立保存，不覆盖 Windows 的 `verification.json`。此项不等于 systemd 首启或整机重启验收。
