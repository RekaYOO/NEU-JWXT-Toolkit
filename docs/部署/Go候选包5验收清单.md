## 逐项核销边界

Windows 解压程序也已用独立数据目录验证 `remote-single`：一个账号启用时，新增第二个账号返回 409；停用第一个账号后可准入第二个；再次启用第一个仍返回 409。重启服务后两个账号的准入状态和单用户限制均保持。此项仅使用管理员操作，不涉及学校登录。

## 已知差异

- 包内 Linux 服务使用 `/var/lib/neu-toolbox`。候选包 5 的 `BACKUP.md` 示例路径有误，请按实际服务配置操作；其服务文件还需要预先创建数据目录。修正后的说明见[运行包](Go运行包.md)、[备份与恢复](Go备份与恢复.md)。
- 包内更新功能检查和下载官方包，不自动安装或回滚。
- 包后源码修复包括显式退出清缓存、拒绝旧会话写回刷新日志、启动时避免重复访问状态请求、成绩页颜色与导航选中色。这些修复不能计入上述两份归档。
