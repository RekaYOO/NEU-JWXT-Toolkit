学校业务由使用者在实际窗口试用。主题的逐页视觉核查仍需覆盖历史业务页的加载、空数据和错误状态。Android 设备验证使用 API 35 模拟器。

考试页已用 `923d3df` Windows 包中的生产网页在 Chrome 检查。375 和 1440 像素宽度分别应用晴蓝、樱空、青庭，六组均能显示考试空列表和查询失败提示。检查使用模拟学期与考试响应，并核对页面的主题主色。加载时检测到活动指示器，其所属区域以及各状态的文字对比度仍待核实。

后续 `a75490e` 成品复验覆盖考试页本身的加载、空列表和查询错误提示。三套内置主题在 320 与 1440 像素下均通过可见性和文字对比度检查，共 18 项。页面在模拟查询完成后从加载提示切换到空列表。

青庭主题下让业务请求返回 503，375 和 1440 像素宽度各打开 12 个一级业务入口。24 次打开均保留目标路由且未捕获页面脚本异常。375 像素宽的导出页占用了 379 像素，已移除手机页头的横向负边距。

在 `c8d7b93` Windows 成品中，用 Chrome 检查 12 个一级入口。晴蓝、樱空、青庭分别在 375 和 1440 像素宽度接收模拟空集合响应与 HTTP 503。144 次组合检查中，响应后均显示主内容区域，路由、页面宽度和浏览器脚本异常检查通过。空集合使用通用模拟数据。晴蓝在首次渲染业务容器前即可读到默认主色，因此等待阶段的采样中包含应用启动画面。
