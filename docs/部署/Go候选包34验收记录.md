# Go 工具箱 RC34 验收记录

同一授权账号通过旧 Python 客户端和新版 Go 客户端分别读取全部学期成绩。两份结果均有记录，记录总数相同。逐条对照 14 个字段，包括学期、课程号、名称、成绩、学分、绩点及通过状态，重复记录也按出现次数核对，结果全部一致。个人数据仅在内存中比较。

四节活动证书验收使用授权账号读取了一张已颁发证书，Go 客户端取得图片后在内存中完成 PNG 解码。另以合成数据验证两张证书中一张下载失败时，压缩包包含成功图片和下载说明，说明准确列出活动名及图片校验失败原因。

GPA 方案通过三会话接口验收。同账号两个 Edge 会话打开同一学期方案后，第一个会话保存修订稿，另一会话提交旧版本收到 409，再读取时得到修订稿。第二个合成账号可以独立保存同名文件，两个账号读回的课程、版本和归属各自正确。

多账号日程验收通过。两个合成账号分别访问同一学期的日程。第一个账号保存日程后，第二个账号读到空日程和初始版本。第一个账号退出后，其原浏览器再次读取返回 401，第二个账号成功保存并读回自己的第一版日程。

学校直连只读查询通过科研训练快照、四节活动、可打印证明目录、评教周期和默认周期的任务列表检查。选课上下文查询返回 `JWXK_NOT_IN_SELECTION_ROUND`。本轮只记录接口执行状态，窗口开放时的选课行为仍待验收。

双会话日程接口验收通过。两个隔离的 Edge 会话登录同一个合成账号，其中一个会话断网，另一个保存日程。重连时，服务端对过期版本返回 409，随后读回的完整日程与写入方保存结果一致。此项在浏览器中通过 HTTP 调用 Go 服务，课表页面的控件另由前端用例验证。

同日追加的直连只读验收使用一次登录，在同一会话中成功解析当前学期个人课表、培养计划报告、实验学期和实验课程列表。个人课表覆盖校区、周次、节次和排课查询。验收仅保留各项执行状态。

2026 年 11 月 23 日，使用本机授权账号在学校直连环境验证。旧客户端通过统一认证后读取教务首页，返回 HTTP 200。新版 Go 客户端独立登录，课表学期列表成功解析并识别出当前学期。考试学期列表、当前学期考试查询及成绩查询也通过新版业务解析。测试仅记录各步骤是否成功，真实响应仅在内存中处理。

个人历史学期课表的导出入口已修复。前端 67 组、627 项测试通过。Windows 成品启动、迁移、升级、备份恢复结果见交付目录的 `verification.json`。Linux 归档通过离线检查，Android 客户端的 31 项网页资源与生产构建一致。独立 Linux 主机重启、Android 真机 HTTPS 和文件保存仍待验收。
