# RC35 使用与验收

版本为 2.2.4。同目录的 `SHA256SUMS` 列出五个交付文件的摘要。

- Windows 用户解压 `NEU-JWXT-Toolkit-2.2.4-windows-amd64-go.zip`，双击 `启动工具箱.cmd`。升级或迁移前先阅读包内的 `BACKUP.md` 和 `IMPORT.md`。
- Linux 用户解压 `NEU-JWXT-Toolkit-2.2.4-linux-amd64-go.tar.gz`，按包内 `README.md` 配置服务。独立主机验收使用 `RC35-linux-acceptance.zip`。
- Android 测试手机安装 `NEU-JWXT-Toolkit-2.2.4-android-arm64-client-debug.apk`，填写服务的 HTTPS 地址。`android-arm64-device-tests.apk` 是对应的设备测试包。

本版修正了学校文本数值两端带空白时的成绩解析。Android 包包含重叠保存时的临时文件清理修复。Go 学业模块和应用层测试通过。Windows 成品启动、备份恢复、升级和迁移验证结果在 `verification.json`。Linux 验收包已在空目录完成归档检查。Android 客户端的 31 项网页资源与本版网页构建逐字节一致。

学校直连与跨账号验收详见 [RC34 验收记录](Go候选包34验收记录.md)。独立 Linux 主机重启、Android 真机 HTTPS 与文件保存、旧插件和课表导出格式兼容、开放轮次选课和学校写入流程仍待验收。

## 接续验收所需条件

### 仍可在开发机推进的工作

- 课程大纲详情已展示历史附件名称，下载转发接口也已实现。列表中的附件标识到页面下载按钮的连接仍待完成，元数据自动预热仍待核对。
- 当前课表导出为 JSON。旧版导出入口和文件格式尚未确认，兼容性仍待核对。旧插件的安装、授权、启停及卸载同样缺少已核实的旧版基线。
- 自动选课需要把后台运行、关闭网页、暂停和重启接续放在同一流程中验证。主题和多账号需按计划书逐项核对，已有日程和 GPA 的双账号检查覆盖其中一部分。

Android 手机和独立 Linux 主机分别用于手机端 HTTPS 与文件保存、系统服务整机重启验收。以上源码和集成工作可独立推进。

RC35 的 Windows 包内网页通过了跨窗口日程验收。第一个 Edge 会话在课表中打开当日日程、添加并保存，第二个独立会话用同一合成账号打开同一天，在页面上读到了刚保存的日程。学校课表使用合成数据，两个窗口的日程均由同一 Go 服务读写。
