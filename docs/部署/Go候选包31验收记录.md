# Go 工具箱 RC31 验收记录

RC31 源码通过前端类型检查和完整前端回归。66 组共 625 项测试全部通过，开启未关闭资源检测后，测试进程正常退出。

版本 2.2.4。交付目录 `dist/go-release-candidate-31/` 包含 Windows 和 Linux 主包、Android 客户端调试包、设备测试包及独立 Linux 验收包。五个文件均已按目录内的 `SHA256SUMS` 复核。

分别从 Windows 包和 Android 客户端包加载网页，在桌面 Chrome 使用 375 和 1440 像素视口复验历史归档。首次读取返回 503 时显示原因，点击重试后成功加载。筛选后仍可导出完整归档。另一窗口删除后刷新详情，页面显示删除提示并撤去导出按钮。复验入口为 `tools/check_selection_archive_export.cjs`。

Windows 成品的启动、迁移、备份恢复和升级结果见交付目录的 `verification.json`。Android 系统文件选择器、手机端 HTTPS 和独立 Linux 整机重启仍待实测。其余项目及既有证据见 [RC30 验收记录](Go候选包30验收记录.md)和[按计划书排列的功能清单](Go候选包28验收清单.md)。

独立 Linux 主机按验收包内说明安装系统服务。首次启动和整机重启后各执行一次以下命令，核对运行用户、数据目录及数据库和密钥文件的所有者与权限。命令只读取文件属性。

```sh
set -eu
pid=$(systemctl show neu-toolbox.service --property=MainPID --value)
test "$pid" -gt 0
test "$(awk '/^Uid:/ {print $3}' "/proc/$pid/status")" = "$(id -u neu-toolbox)"
test "$(sudo stat -c '%a %U %G' /var/lib/neu-toolbox)" = '700 neu-toolbox neu-toolbox'
for file in toolbox.db vault.key; do
    test "$(sudo stat -c '%a %U %G' "/var/lib/neu-toolbox/$file")" = '600 neu-toolbox neu-toolbox'
done
```
