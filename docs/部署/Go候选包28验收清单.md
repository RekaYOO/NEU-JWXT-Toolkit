课表导出的迁移基线待确认。旧版 `main` 的 `c46d785` 中，已检查的查询课表页面、日程组件和课表路由均未定位到文件下载入口；可定位的 ICS 下载入口在考试页面 `ExamPage.js`。计划书第 3 节单列了课表的“原有导出”，该项应继续保留，需查明旧版入口或确认所需文件格式后验收。
