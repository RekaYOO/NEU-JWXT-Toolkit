# 工具箱 2.2.4 三平台试用说明

本批成品来自 `refactor/go-web-toolbox` 分支提交 `c8d7b93`。

| 平台 | 首次使用 |
| --- | --- |
| Windows x64 | 解压 Windows ZIP，双击 `启动工具箱.exe`，从浏览器进入工具箱。托盘菜单可退出程序。 |
| Linux x64 | 解压 Linux 压缩包，按包内 `README.md` 配置服务。远程多用户模式使用 HTTPS，管理员在 `/admin` 初始化并管理准入。 |
| Android ARM64 | 安装 `client-app-arm64-debug.apk`，填写配套服务端的 HTTPS 地址。 |

从旧版迁移时先阅读桌面包内的 `BACKUP.md` 和 `IMPORT.md`。外观入口为「系统设置 → 外观与主题」，可取消预览或恢复站点默认。
