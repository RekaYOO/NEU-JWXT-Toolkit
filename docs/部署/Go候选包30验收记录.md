# Go 工具箱 RC30 验收记录

版本 2.2.4。交付目录为 `dist/go-release-candidate-30`。目录内 `SHA256SUMS` 覆盖 Windows、Linux、Android 客户端、Android 设备测试包和独立 Linux 验收包。

11 月 23 日在 Windows 上复验重构分支。前端类型检查通过，66 组 625 项前端测试全部通过，启用未关闭资源检测后正常退出。Go 全量测试禁用结果缓存后通过，`go vet ./...` 通过。

- Windows 成品的启动、备份恢复、迁移及升级检查见交付目录中的 `verification.json`。
- 选课轮次与查看学期不同时，课程详情使用查看学期的冲突和上课安排。前端用例 `isolates same-code course details by selection term` 核对两个学期的冲突数据。Chrome 在 1440 像素宽度加载 RC30 Windows 包内网页，预览轮次课程后切换到历史学期，打开同名同号课程，核对教室为“历史教室203”且原轮次的预览标记已消失。复验脚本为 `tools/check_selection_preview_detail.cjs`。
- 从 RC30 Android APK 解出网页，在 Chrome 的 375 和 1440 像素宽度执行 `tools/check_selection_archive_export.cjs`。筛选后下载的 JSON 与完整模拟归档一致，模拟 Android 保存接口收到的文件名、类型及分块重组后的内容均通过核对。系统文件选择器保存和离线重开仍待真机验收。
- 独立 Linux 验收包在空目录解压后通过归档检查。服务启动和整机重启恢复仍需独立 Linux 主机。
- Android 原生单元测试报告包含共享模块 24 项和客户端 2 项，均通过。ARM64 调试版静态检查有一项提示，涉及切换服务器时将会话来源同步写入本地设置。原生 HTTPS 连接及系统文件选择器仍待真机验收。

桌面浏览器还从历史学期切回选课轮次，再次打开原先预览的课程。详情恢复“正在预览”标记，历史教室已清除。整个往返过程使用模拟课表，选课和退课请求计数均为零。

选课历史删除专项 `TestJWXKArchiveHistoryIsolationDeletionAndLateMerge` 使用两个合成账号，连续通过五轮。归档所有者删除后，先前读取旧版本的后台合并返回冲突，再次查询选课目录后，读取已删除归档仍返回 404。

Chrome 在 375 和 1440 像素宽度使用同一浏览器会话打开归档详情和列表。列表窗口确认删除时，模拟服务收到一次删除请求。刷新原详情窗口后，页面提示归档已删除，导出按钮消失。复验入口为 `tools/check_selection_archive_export.cjs`。

其余功能沿用[逐项验收清单](Go候选包28验收清单.md)中标注的测试版本和待验事项。学校接口操作按批次审批。
