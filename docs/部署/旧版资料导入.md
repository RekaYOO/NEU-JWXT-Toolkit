# 旧版资料导入

Go 新版提供 `toolbox import-legacy` 维护命令，先预览，再按预览摘要导入。
旧 Python 数据目录始终只读；命令不访问学校、不恢复登录，导入的自动任务不会自行启动。
导入前建议分别保留旧目录副本及[新版加密备份](Go备份与恢复.md)。

## 当前支持的资料

| 资料 | 旧版来源 | 归属判断 |
|---|---|---|
| GPA 模拟方案 | `成绩/gpa_simulations/<账号SHA256前24位>/*.json`；兼容 `成绩/*.json` | 文件 `export_info.exported_by` 必须与指定账号一致 |
| 绩点偏好 | `gpa_preferences/<账号SHA256>.json` | 指定账号的哈希路径，只接受旧版两种策略或自动选择 |
| 科研收藏 | `research_training_favorites.json` | 只读取 `users[指定账号].records`，保留批次及课题快照；不迁入联系方式和申请理由 |
| 选课方案 | `config.json` 中 `course_selection_plans` | 只读取 `账号:轮次` 键，并核对方案轮次；不会启动关联任务 |
| 个人日程与调休 | `timetable_agendas/<账号SHA256>/<学期SHA256>.json` | 账号与学期均由命令显式指定；保留已结束学期标记 |
| 课程历史归档 | `course_selection_catalog_history.json` | 只读取指定账号的归档，核对轮次和学期，保留教学班、来源及课次 |
| 自动抢课、空位换课、策略投权任务 | `course_selection_tasks.json` | 按账号导入配置与历史摘要；运行中任务转为暂停，待确认操作保留独立核验记录 |
| 轮次自动化设置 | `course_selection_automation_settings.json` | 只读取 `账号:轮次` 键，保留调度、最终窗口与通知偏好，不启动任务或发送邮件 |

目标账号须已在新版建立并启用：远程部署由管理员准入，本地部署可先登录建立账号。
命令不会自行增加准入、绕过停用或猜测共享配置的归属。

## 预览

```powershell
.\toolbox.exe import-legacy --data 'D:\toolbox-data' --source 'D:\old-toolbox\data' --account '你的学号' --terms '2026-2027-1,2025-2026-2'
```

Linux 使用同样参数及实际目录即可。`--data` 是已存在的新版本数据目录；`--source` 是
旧版数据根目录。`--terms` 为可选的日程学期代码列表。旧日程文件名只有哈希，不能从文件名
可靠反推学期，因此不提供学期代码时不会导入日程。

输出 JSON 报告列出来源、目标文档、状态和 `digest`，不输出课程内容、密码或凭据。
状态 `new` 表示待导入，`unchanged` 表示目标已有相同内容，`conflict` 表示已有不同内容
或已删除记录。预览不写入业务文档。

## 执行

核对报告后，使用完全相同的路径、账号、学期参数，并添加报告中的摘要：

```powershell
.\toolbox.exe import-legacy --data 'D:\toolbox-data' --source 'D:\old-toolbox\data' --account '你的学号' --terms '2026-2027-1,2025-2026-2' --apply-digest '预览报告中的digest'
```

命令重新读取来源并核对摘要，随后把新文档作为一个事务写入。来源变化、账号被撤权、
目标冲突或并发修改都会停止，不留下部分导入结果。重复执行相同资料不会创建副本。
用户已删除的新版文档不会被旧文件复活。冲突时应先在隔离副本中核对资料并改名或整理，
再次预览；命令不提供强制覆盖开关，也不修改旧文件。

普通文件最大 4 MiB；课程归档集合文件最大 128 MiB，单轮次归档最大 64 MiB、最多五万个教学班。
一次最多 256 个目标文档、合计 128 MiB；超限在写入前拒绝。
文件读取限制在指定旧目录内，目录穿越或指向目录外的链接不能作为来源。

课程归档保留来源范围，`ALLKC` 全校发现课程不会混入轮次可选目录或策略样本。
导入后可在新版历史归档和本地目录查询中查看。归档标识按新版规则重新生成；旧页面保存的
归档链接需要从新版列表重新打开。旧扫描过程、任务标识和分页进度不续跑，导入状态标为
`imported`；已归档标记及完整性状态仍保留。命令不发起远端查询。

## 自动任务的启动边界

自动任务导入后需手动启动。旧版已结束任务保持结束；含待确认提交的任务标为待核验，
启动后逐项只读查询学校结果。未确认时再次暂停，不会重复提交；学校确认后才继续下一步。
取消任务仍保留待确认操作记录，防止其他入口重放。旧扫描进度和待执行投权队列不直接续跑，
启动后根据学校现状重新计算。无法确定教学班或同一课程存在矛盾待确认记录时拒绝整个导入。

## 旧版共享设置归属

旧版 SMTP、成绩追踪及认证恢复设置属于整个进程，没有可靠的账号字段。迁移时必须
明确指定它们归属哪个新版账号。建议停下新旧服务后执行维护命令，避免运行中设置变化。

```powershell
.\toolbox.exe import-legacy --data 'D:\toolbox-data' --source 'D:\old-toolbox\data' --account '你的学号' --shared-settings-owner '你的学号'
```

这个选项切换为**仅导入共享设置**，不同时导入普通资料，不能与 `--terms` 混用。
归属参数必须与目标账号一致。查看预览后，用相同参数加 `--apply-digest '预览摘要'` 应用。
预览只列来源、目标类型和冲突状态，不展示 SMTP 地址或密码。

- `system_mail_config.json`：导入邮件配置及密码；完整配置在新版加密保存，不写入普通文档。
- `grade_tracking_config.json`：保留检查间隔和每日时段，强制关闭追踪，需用户手动开启。
- `auth_recovery_config.json`：保留站点地址和链接时长，按新版地址规则校验；远程部署要求 HTTPS。
- 缺少独立邮件/恢复配置时，兼容更早版本追踪配置中的 SMTP 字段及 `site_url`。

设置和新邮件凭据同一事务写入，冲突则全部不写入；不覆盖已有不同配置，重复导入幂等。
邮件导入标记防止已删除凭据被旧文件复活。迁移命令不发送邮件、不启用追踪，旧队列、
已发送历史、恢复上下文、签名密钥及登录会话不恢复；现有后台服务重新运行后按新版配置工作。

## 尚未接续的资料

学校会话和学校登录密码不会由本命令导入，需重新登录。
检测到已知未处理文件时会列出警告；`config.json` 只处理有明确账号键的选课方案。
浏览器偏好及 IndexedDB 不在服务器目录中，不能由此命令迁入。
同一浏览器保存个人课表失败时，上一次成功保存的离线恢复账号不变；清除其他账号的课表缓存也不会移除该账号的恢复标记。这个标记不包含课表内容，不能用来跨设备迁移课表。
成绩页和培养计划页的列设置仍使用旧版浏览器存储键。在同一浏览器配置、同一站点（协议、主机和端口均相同）内可直接读取原有显示选项与数值列宽；单条记录损坏不会使其他列失效。更换端口、浏览器或设备不会自动复制这些设置。这不涉及个人课表缓存。
这些范围仍需继续完成独立迁移，不能把本命令视为旧版全部数据接续已经完成。
