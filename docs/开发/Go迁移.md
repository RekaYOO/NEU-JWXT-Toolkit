# Go 重构实施入口

成绩追踪已有账号配置接口、学校时区窗口及共享成绩比较模型。配置部分更新、稳定快照和分项目标
筛选已有测试；手动检查与状态已接通共享成绩资源，失败保留基线，成功快照和状态原子保存。
启停、后台检查、共享缓存消费、初始/变更邮件与分项已接通；快照、状态和发件意图原子保存，
发送回执区分排队与实际成功，关闭取消旧任务结果与待发送邮件。认证失效已接通去重提醒、
一次性签名恢复页及发送时链接组装；真实账号、邮件服务与浏览器端到端验收仍待完成。

本分支在原仓库内逐项迁移到 Go＋SQLite 后端和 React＋TypeScript＋Vite 前端。
原有业务和移动端范围不缩减；执行预算为用户指定的24小时，不重新估算或自动延期。
本页记录实际实现及验证入口，不代表完整产品已经交付。

## 运行和验证

构建需Go 1.24或以上、Node 20.19或以上；本机当前使用Go 1.27.4和Node 25.0.0。
Go已下载官方Windows归档并核对官方SHA-256，独立安装于
`%LOCALAPPDATA%/NEU-JWXT-Toolkit-build/sdk/go`，没有改写系统PATH。

```powershell
# 项目根目录；使用已安装的Go时可直接调用go
$goExe = Join-Path $env:LOCALAPPDATA 'NEU-JWXT-Toolkit-build/sdk/go/bin/go.exe'
& $goExe test ./internal/... ./cmd/...
& $goExe build -o dist/toolbox.exe ./cmd/toolbox

# 前端目录
npm run typecheck
npm run build
npm run test:performance
npm test

# 项目根目录，独立迁移运行入口
./dist/toolbox.exe -listen 127.0.0.1:8000 -assets frontend/build -data data/go
```

依赖下载受网络影响时可设置GOPROXY到可信Go模块镜像，保留Go校验和数据库验证。
Go测试限定项目自有cmd/internal目录，避免扫描前端node_modules中的第三方Go示例。
`NEU_JWXT_DATA_DIR`优先于数据目录参数。默认`data/go`与旧资料隔离，尚未实施旧资料导入；
不得把直接打开旧cache.db当作资料迁移。健康响应的`migration_in_progress`目前为true。

## 必须保持的联动

- 文档保存由认证后的账号上下文提供归属，不接受浏览器自行声明账号作为授权。
- 停用后的既有文档不可读写；generation已用于会话与保存事务校验，待继续接入业务任务。
- 更新和删除必须带预期revision；删除保留墓碑，旧标签页的初次创建或旧版本保存不能复活资料。
- 文档与可重建缓存、可靠任务、凭据分开建模；当前document命名空间不接受学校Cookie或密码。
- Go的可重建缓存位于同一toolbox.db的cache_entries/cache_events表；方案、会话和密文分别存表。清理缓存必须只操作缓存表，不能删除整个数据库或vault.key。
- 成绩语义revision排除学校详情引用，培养计划排除计算时间及列表顺序；引用变化仍更新缓存正文。成绩变化使同账号培养计划失效，计划保存其依赖成绩revision。
- 本机离线接口优先当前访问会话，否则读取最近有缓存的有效账号；远程模式必须具有当前账号访问会话，绝不退回其他账号。离线接口只调用缓存读取，不接受写入或创建后台任务。
- 前端继续保留旧manifest字段、十六进制哈希、压缩文件和路由恢复，以兼容Python及Android过渡运行。
- 远端写请求不自动重放；学校响应未知时进入只读结果核验。后续认证迁移必须保持二维码/短信候选Session。
