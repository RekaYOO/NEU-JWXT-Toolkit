# 移动端能力矩阵

本文用于核对“桌面能力 → 手机入口”，防止响应式改造只保留展示而遗漏筛选、详情、
配置或写操作。它描述入口和验收契约，不固化页面内部结构；当功能演进时应同步更新。

## 统一交互

| 桌面交互 | 手机交互 | 共同约束 |
|---|---|---|
| 完整工具栏 | 2-3 个等宽操作，或主操作 + 有名称的分组菜单 | 复用同一处理函数和禁用状态；不得随机换行 |
| 表格筛选、排序 | 筛选抽屉 + 活动条件计数/标签 | 复用同一筛选值和派生结果 |
| 表格完整列 | 摘要卡片 + 点击详情 | 两次操作内可见全部业务字段 |
| 侧边详情/弹窗 | 全宽详情或底部抽屉 | 标题、关闭入口和操作持续可见 |
| 表格批量操作 | 条目选择 + 底部操作栏 | 数量、确认、提交中和结果语义一致 |

仅离线能力、运行模式和权限边界可以隐藏页面或禁用操作。手机屏幕较小、字段低频或
按钮较多都不是删除功能的理由。

## 页面能力对照

| 页面 | 桌面能力 | 手机入口与验收 |
|---|---|---|
| 成绩 | 学期/属性/状态/成绩/绩点/学分/影响值筛选，排序，分页，平均绩点，按需分项详情，GPA 模拟 | 快捷视图之外提供完整筛选抽屉；成绩数字可点击并先显缓存、再在线查询单科动态分项，离线只读缓存；筛选同时驱动列表、分页和平均绩点；GPA 的添加、编辑、删除、计划导入、文件导入、保存、撤销和冲突协调均可达；文件列表弹窗按内容增高、超出视口后内部滚动，文件操作始终可达 |
| 培养计划 | 类别树、搜索、课程详情、类别与总学分统计、GPA 导入 | 顶栏保留可点击的学分悬窗；搜索、类别、刷新在手机端等宽稳定排列；类别抽屉可与搜索和快捷视图组合；课程卡打开完整详情；类别统计与 GPA 导入可达 |
| 考试 | 学期、待考/全部、详情、ICS 导出 | 窄屏工具栏不挤压；考试卡完整显示时间、地点、座位、类型和状态；导出保留 |
| 系统日志 | 文件、范围、分类、日期、级别、关键词、刷新、下载、清理 | 日志卡片打开完整消息；统一筛选抽屉；刷新、下载、清理均可达，清理二次确认 |
| 实验选课 | 课程/项目展开、实验班详情、选课和退课 | 纵向项目卡和接近全屏班次面板；教师、时间、地点、容量、冲突先于操作；选退保持确认和防重复提交 |
| 科研训练 | 资格、搜索筛选、报名/收藏/已确认、详情、报名和取消 | 简短资格条件直接显示为紧凑摘要，不机械折叠；筛选抽屉；三个视图清晰可切换；卡片只用一种主状态和稳定双操作区；全屏报名表单保留；离线时缓存可读、联网与写操作禁用并说明 |
| 自动评教 | 任务、课程、详情、单课评价、选择、策略、批量提交 | 须知确认后收成状态条并可重看；任务和课程保持返回上下文；移动卡片完成评价；选择数量和批量提交进入底部操作栏；确认边界不变 |
| 成绩追踪 | 即时开关、状态、检查策略、邮件配置、测试、立即检查、保存 | 开关与状态首屏可用；全部字段单列可编辑；立即检查和保存使用底部操作栏；邮箱、数字和 URL 使用对应键盘类型 |
| 导出下载 / 四节活动 | 工具总览、入页时间卡、自动/按需模式、日期范围、并列快捷视图、统计、活动列表、详情、刷新、证书打包 | 总览单列卡片；每次进入先显示中文时间卡和 `YYYY-MM-DD` 日期，默认当前学年 8/31–次年 8/30；历史学年快捷项不改变当前默认；首次无数据时加载动画在当前视口直接可见，筛选/统计待数据返回后出现；默认工作区只显示等宽筛选入口、证书打包入口和可换行筛选摘要，底部抽屉提供学年、日期、分区、搜索及“日期范围内/全部/时间未知/有证书/有奖”五项查看范围，并支持重置/应用；确认按需模式时先删除当前账号四节活动缓存，失败提示在窄屏可见且不继续；320/375/430px 无横向溢出，活动摘要卡打开全屏详情；离线仅有缓存时只读并禁用按需、刷新和打包 |
| 登录与恢复 | 直连、WebVPN 密码、微信扫码、短信、离线、访问密码、追踪恢复 | 所有认证方式保留；访问方式同行可选；二维码、实时倒计时、短信输入和错误状态适配窄屏及虚拟键盘 |
| 导航 | 所有当前模式允许页面、当前页名、用户菜单 | 抽屉包含同一允许页面集合；顶栏始终保留导航和用户菜单。当前页通常显示标题；培养计划可用明确标注的学分悬窗占据中间上下文位 |

## 新功能登记

新增或修改用户功能时至少记录：

1. 桌面入口和手机入口分别在哪里。
2. 手机首屏优先答案是什么，低频字段放在哪里。
3. 触屏、键盘和不依赖悬停的入口如何实现。
4. 320px 下如何换行或降为单列，是否适配动态视口与安全区。
5. 加载、空、失败、离线、禁用、提交中和成功状态是否等价。
6. 写操作的资格校验、确认、防重复提交和写后刷新是否共用同一业务函数。

验收至少覆盖 `320×800`、`375×812`、`430×932`、`768px`、窄高度横屏和
`1440px` 桌面。远端写操作使用模拟响应或安全预览，不因界面验收修改真实教务数据。
