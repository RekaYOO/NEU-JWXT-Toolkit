# 第三方系统接口与参数索引

本文是开发参考，不是对外 API 文档。表中的路径和字段来自当前 `backend/core` 适配器；学校
系统可能在不同学期调整字段或返回结构，修改代码前应先用匿名响应夹具补测试。前端不得直接
访问这些第三方地址，统一经认证客户端和对应的 Router 调用。

## 阅读约定

- `jwxt.neu.edu.cn` 是综合教务系统；成绩、培养计划、课表、考试、课程大纲、实验选课、科研训练、
  证明打印都复用同一个 `NEUAuthClient` 会话。
- `jwxk.neu.edu.cn` 是独立选课系统；必须先建立 JWXK 服务会话并激活 `batchId`。
- `zljk.neu.edu.cn` 是教学质量评价系统，使用它自己的 JWT；不能把 JWXT Cookie 当作评教 token。
- `cxcy.neu.edu.cn` 的四节活动页面是登录后的 HTML 页面，当前实现解析页面和证书链接，不把页面
  私有参数伪装成稳定 JSON API。
- `code`、`datas`、`rows` 是综合教务常见响应包装；不要把 `WID`、`secretVal`、Cookie、JWT 或
  二维码内容写入日志、文档示例或前端状态。

## 1. JWXK 选课系统

适配器：`backend/core/course_selection/jwxk.py`。服务入口为
`https://jwxk.neu.edu.cn/xsxk/auth/cas`；所有请求还会带当前轮次的 `batchid`（请求头）或
`batchId`（表单字段）。`ALLKC` 只是全校目录查询代码，不能作为抢课、投权、退选的提交类型。

### 轮次、账号和结果

| 方法与路径 | 请求参数 | 关键响应字段及含义 |
|---|---|---|
| `POST /xsxk/web/now` | 无 | `currentTime` 官方时间，`onlineCount` 在线人数 |
| `POST /xsxk/web/studentInfo` | `token`：JWXK 服务 token | `student.electiveBatchList` 账号轮次；`schoolTerm` 学期；`beginTime/endTime` 起止时间；`typeCode` 轮次模式（`02` 抢选、`04` 权重）；`canSelect` 是否可进入；`needConfirm/isConfirmed` 须知状态；`menuList` 真实课程范围 |
| `POST /xsxk/elective/user` | `batchId`：轮次代码 | `student.termWeightList[].termCode/weight` 学期剩余权重；`electiveBatchList` 轮次属性；`major/college/campus` 账号基础信息 |
| `POST /xsxk/elective/select` | 无 | 当前轮次已选结果（只用于抢选结果 feed） |
| `POST /xsxk/volunteer/select` | 无 | 当前轮次权重投放结果（普通权重 feed） |
| `POST /xsxk/volunteer/xgxk/select` | 无 | 培养计划/专项权重投放结果（通识等扩展 feed） |
| `POST /xsxk/elective/neu/deselect` | 无 | 退选/撤回结果；读取时也用于获取可撤回材料 |

### 课程目录与核验

`POST /xsxk/elective/clazz/list` 使用 JSON 请求体。当前代码发送的核心参数如下：

| 参数 | 含义 |
|---|---|
| `teachingClassType` | 真实目录/业务范围，例如任务推荐班、培养计划内课；不能伪造为 `ALLKC` 写入 |
| `pageNumber/pageSize` | 官方分页 |
| `orderBy` | 官方排序表达式，后端会先做白名单校验 |
| `KEY` | 课程名称或课程代码关键词 |
| `campus` | 校区代码，如 `01`；界面转换成“浑南校区”等名称 |
| `SKXQ` | 上课星期（星期代码） |
| `KSJC/JSJC` | 起止节次 |
| `KCLB/KCXZ` | 课程类别、课程性质（部分批次需本地语义匹配，不能直接把显示名当代码提交） |

课程/教学班原始字段（代码中的规范化名称在右侧）：

| 官方字段 | 含义 |
|---|---|
| `KCH` / `KCM` | 课程代码 / 课程名称 |
| `JXBID` / `KXH` | 教学班 ID（缺一时按另一个兼容） |
| `SKSJ` | 多条上课安排数组 |
| `SKZC` / `SKZCMC` | 周次位图 / 周次显示文本；位图优先，冲突要标解析异常 |
| `SKXQ` / `KSJC` / `JSJC` | 星期 / 起始节 / 结束节 |
| `SKJS` / `SKJSLB` | 教师文本 / 教师明细 |
| `YPSJDD` | 官方多条地点安排；后端按课次签名匹配，不把整段复制到每个课次 |
| `XXXQDM` / `XXXQMC` | 校区代码 / 校区名称 |
| `KRL` | 课程容量 |
| `YXRS` | 抢选已选人数 |
| `QZXKRS` | 权重轮次已投注人数 |
| `TRQZ` | 当前课程已投权值 |
| `DYZYRS` | 第一志愿人数（若官方返回） |
| `KCLB` / `KCXZ` | 任务课程类别 / 课程性质 |
| `XGXKLB`、`XGXKLBDM` | 通识/专项选修子类别名称 / 代码 |
| `KSLX`、`KSLXMC` | 考试类型代码 / 名称 |
| `CJJLFS`、`CJJLFSMC` | 成绩分制代码 / 名称 |
| `SFYX` / `SFYM` / `SFCT` | 已选标记 / 满员标记 / 官方冲突标记 |
| `secretVal` | 提交所需的短期材料；仅后端内存使用，绝不展示或记录 |

目录存在不代表本轮可选。`POST /xsxk/elective/check` 使用表单 `clazzId`、`secretVal` 做官方
资格核验；当前批次通过请求头 `batchid` 传递。精确命中教学班、来源范围和核验成功后才允许写操作。

### 写操作

| 方法与路径 | 表单参数 | 适用模式 |
|---|---|---|
| `POST /xsxk/elective/clazz/add` | `clazzType`、`clazzId`、`secretVal` | 抢选 `02` |
| `POST /xsxk/elective/neu/clazz/weightAdd` | 课程/教学班 ID、真实 `clazzType`、`secretVal`、投权值等官方字段 | 权重 `04` |
| `POST /xsxk/elective/neu/clazz/del` | 官方返回的课程 ID、`secretVal`、来源标识 | 抢选退课或权重撤回 |
| `POST /xsxk/elective/batch/confirm` | 当前 `batchId` 及确认字段 | 轮次须知确认 |

写请求不自动重放；响应超时只能核验结果。`devoted_weight=0` 本身不能判定抢选，必须结合
当前轮次类型、结果 feed、批次和人数/容量。

## 2. 综合教务：成绩、培养计划和课表

适配器分别位于 `backend/core/academic/api.py`、`backend/core/academic_report.py` 和
`backend/core/timetable/api.py`。综合教务通常返回 `code="0"` 表示成功。

### 成绩与培养计划常见字段

| 官方字段 | 含义 |
|---|---|
| `XNXQDM` / `XNXQMC` | 学年学期代码 / 名称 |
| `KCH` / `KCM` | 课程代码 / 名称 |
| `XF` / `XS` | 学分 / 学时 |
| `XSZCJ` | 原始成绩 |
| `JD` | 绩点 |
| `KCXZDM` / `KCXZDM_DISPLAY` | 课程性质代码 / 显示名 |
| `KCLBDM_DISPLAY` | 课程类别显示名 |
| `XGXKLBDM_DISPLAY` | 通识选修类别显示名 |
| `KSLXDM_DISPLAY` | 考试类型显示名 |
| `SFJG_DISPLAY` | 是否及格显示值 |
| `WID` | 成绩或课程记录引用 ID；只作为内部详情引用 |

### 课表接口

| 方法与路径 | 参数 | 用途 |
|---|---|---|
| `POST /jwapp/sys/jwpubapp/modules/zdgl/xnxqcx.do` | `SFSY=1`、`pageSize`、`pageNumber`、`*order` | 学期列表 |
| `POST /jwapp/sys/jwpubapp/modules/gg/cxmrxnxq.do` | `CSDM=SYS`、`ZCSDM=DQXNXQDM` | 当前学期 |
| `POST /jwapp/sys/kbbpapp/api/schoolCalendar/getTermWeeks.do` | `XNXQDM` | 教学周 |
| `POST /jwapp/sys/kbapp/api/wdkbcx/getMyScheduledCampus.do` | `XNXQDM` | 我的课表校区 |
| `POST /jwapp/sys/kbapp/api/wdkbcx/getMySectionList.do` | `XNXQDM`、`XQDM` | 我的课表节次 |
| `POST /jwapp/sys/kbapp/api/wdkbcx/getMyScheduleDetail.do` | `XNXQDM`、`XQDM`、周次/节次条件 | 我的课表安排 |
| `POST /jwapp/sys/kbapp/api/qxkbcx/getScheduleDetail.do` | `XNXQDM`、`XQDM`、`KBLX` 等对象条件 | 班级/教师/教室课表 |

课表常见字段：`XNXQDM` 学期、`XQDM` 校区、`JC/KSSJ/JSSJ` 节次与起止时间、`ZC` 周次、
`KCM/KCH` 课程名与代码。`KBLX` 是课表对象类型，具体值由 `timetable/api.py` 的模式配置提供。

## 3. 课程大纲

适配器：`backend/core/course_outline/api.py`，基址为
`https://jwxt.neu.edu.cn/jwapp/sys/kccx`。

| 方法与路径 | 参数 | 用途 |
|---|---|---|
| `POST modules/dgcx/cxlb.do` | `querySetting`（JSON 规则数组）、`pageNumber`、`pageSize`、`*order=+KCH` | 课程检索 |
| `GET jwapp/code/<字典 UUID>.do` | 无 | `KKDWDM` 开课单位、`KCCCDM` 课程层次、`KCJBDM` 课程级别 |
| `POST modules/kcdgwhgl/cxkcxxx.do` | `KCH` | 基本信息 |
| `POST modules/kcdgwhgl/cxkcdgxx.do` | `KCH` | 教学大纲 |
| `POST modules/kcdgwhgl/cxkcjcxx.do` | `KCH` | 课程简介 |
| `POST modules/kcdgwhgl/<分组接口>` | `KCH` | 培养目标、考核、治理、附件等详情分组 |

`querySetting` 中规则使用 `name`（字段）、`builder`（include/equal/between）、`linkOpt=AND`、
`value`。代码和课程名搜索分别使用 `KCH`、`KCM`；学分/学时范围使用 `XF`、`XS`。

## 4. 自动评教

适配器：`backend/core/evaluation/api.py`，基址为 `http://zljk.neu.edu.cn`。该系统使用独立
JWT，后续请求带 `Authorization: Bearer <JWT>` 和 `X-Tenant-ID: default`。

| 方法与路径 | 请求体/参数 | 关键字段 |
|---|---|---|
| `POST /api/qsmart/datacenter/TSysCycleController/tSysCycle/findCycle` | 空 JSON | `cycleid`、`value` 学期、`isdefault` 当前学期 |
| `POST /api/TSysDdJxapController/tSysDdJxap/findJdpXqByTaskidHZ` | `page`、`xnxq` | `taskid`、`taskname`、`count`、`ypcount`、`wpcount` |
| `POST /api/TSysDdJxapController/tSysDdJxap/findJdpXqByTaskid` | `page`、`kcmc`、`jgxm`、`xnxq`、`taskid` | `xspjid`、`kcmc`、`jgxm`、`issubmit` |
| `POST /api/TSysDdJxapController/findPjDxqk` | `taskid` | 已保存评价状态 |
| `GET /api/TSysDdEvalTargetController/queryEvalTargetTreeForEval` | `libid`、`tkid`、`taskid` | `zbid` 指标 ID、`zbmc` 名称、`evaltype` 类型、`sfdx` 单/多选、`sfbt` 必填、`weight` 权重、`fz` 分值 |
| `POST /api/TSysDdKbxxController/getTasklib/{taskid}` | 空 JSON | 任务关联指标库 |
| `POST /api/TSysDdJxapBcpController/queryKzInfo` | `taskid` | `dffs`、`gffs` 等官方开关 |
| `POST /api/TSysDdEvalResultJdpController/tSysDdEvalResultJdp/saveJdp` | `resultList`、`task` | `xspjid` 学生评教对象、`zbid` 指标、`dfdj` 等级、`score` 得分、`xnxqid` 学期、`rwid` 任务、`libid` 指标库 |

评教提交是不安全可重放操作。指标和选项必须来自当前任务，不能在前端硬编码或复用旧任务 ID。

## 5. 活动证明与学籍证明

### 四节活动快速导出

适配器：`backend/core/festival_activities.py`，站点为 `https://cxcy.neu.edu.cn`。实现读取登录后
四个分区的用户中心 HTML：`originality` 创意节、`popscience` 科普节、`technical` 科技节、
`business` 创业节。活动详情链接必须是 `/&lt;section&gt;/comp/front/comp/info?id=...`，证书只接受
官方静态证书目录下的 `png/jpg/webp`，后端会校验主机、路径和查询参数后才写入本地归档。
这里没有稳定 JSON 参数表；不要把抓到的页面 CSS 类名当作接口契约。

### 学籍证明打印

适配器：`backend/core/academic_documents.py`，基址为
`https://jwxt.neu.edu.cn/jwapp/sys/zmdyneu`。

| 方法与路径 | 参数 | 说明 |
|---|---|---|
| `POST zmdy/queryAllZmdy.do` | 空表单 | 分组返回 `CDMC`、`REPORTS[].WID`、`REPORTS[].CDMC`、`XNXQWD_DBDX` |
| `POST zmdy/printBefore.do` | `wid` | 非消耗性打印权限预检，检查 `success`、`fwlx`、`hasQx` |
| `GET zmdy/printZm.do` | `wid` | 生成并下载证明；该请求不自动重试 |

考试和科研的具体响应仍以对应适配器的规范化模型为准。

## 7. 修改接口前的检查清单

1. 先在对应 `backend/core` 适配器中确认 URL、方法、请求编码和字段，不从页面显示文字猜参数。
2. 为新增字段保留原始值和显示值的边界；代码字段如 `KCLB`、`XGXKLBDM` 不直接展示给用户。
3. 读请求纳入缓存/刷新协调器；写请求声明不可自动重试、成功后的失效资源和核验路径。
4. 用匿名夹具覆盖空响应、登录过期、官方业务拒绝、字段缺失和新旧字段别名。
5. 更新对应功能文档与本索引；不要把真实账号响应、token、`secretVal` 或完整请求头提交到仓库。
