# 快速开始

## 安装并登录

1. 从 [GitHub Releases](https://github.com/RekaYOO/NEU-JWXT-Toolkit/releases/latest) 下载安装包，并用同页的 `SHA256SUMS.txt` 校验。
2. Windows 解压 `*-windows-amd64-go.zip` 后双击 `启动工具箱.exe`。Linux 按[服务端安装说明](部署/Go运行包.md#linux-服务)配置，Android 按[安装说明](部署/Android安装.md)选择本地版或远程客户端。
3. 登录页选择校内直连或 WebVPN，再用学号密码、智慧东大扫码或微信扫码登录。远程部署需先通过站点访问验证。

已有旧版安装时，先保留程序和资料，按[旧版资料导入](部署/旧版资料导入.md)试运行并导入。

## 源码运行

使用 Go 1.24+、Node.js 22 和 npm，在仓库根目录运行以下命令。

```bash
npm --prefix frontend ci
npm --prefix frontend run build
go run ./cmd/toolbox --mode local-single --listen 127.0.0.1:8000 --data ./data-go
```

打开 `http://127.0.0.1:8000`，按 Ctrl+C 停止。数据保存在 `data-go`，更新代码时保留该目录。前端改动可通过 `npm --prefix frontend start` 使用 Vite 开发服务器，Go 后端继续监听本机 `8000`。

维护和升级见[运行包说明](部署/Go运行包.md)。测试、构建和版本标签规则见[发行与 CI/CD](开发/发行与CI.md)。
