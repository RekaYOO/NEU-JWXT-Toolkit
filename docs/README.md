# 文档中心

这里是 NEU 教务系统工具箱的说明书入口。根目录 README 只负责项目介绍和安装选择；
具体操作、部署与开发规则从本页进入。

## 第一次使用

1. [快速开始](快速开始.md)：选择发行版或源码运行，完成首次登录。
2. [Windows 本地安装](部署/Windows本地安装.md)：Windows 便携版、数据位置与安全校验。
3. [Linux 轻量服务](部署/Linux轻量服务.md)：systemd、访问密码、反向代理、升级和卸载。
4. [WebVPN 校外访问](功能/WebVPN校外访问.md)：直连、WebVPN、二维码、短信与会话恢复。
5. [离线使用](功能/离线使用.md)：可以离线读取的数据和不可用操作。

## 文档维护规则

- 用户操作以 `frontend/src/features/featureRegistry.js`、页面组件和实际路由为证据。
- API、认证、缓存和持久化规则以对应 schema、router、core 模块及测试为证据。
- 功能文档描述当前可用行为，不保存开发过程、聊天记录、临时方案或未实现愿望。
- 实现发生变化时，同一提交更新相关功能文档；历史变更交给 Git 和 Release Notes。
- 所有仓库内链接使用相对路径。真实账号、Cookie、token、业务响应和个人数据不得进入文档。
